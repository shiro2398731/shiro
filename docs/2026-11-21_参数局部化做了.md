# 参数局部化：做了（2026-11-21 22:45）

> 白默：「量化值不该让我们手动调，不然像工艺品。」
> Flow-Lenia（arxiv 2212.07906）：参数该 **dynamic and localized**。
> **做了**：`_decay_factor` 从「出生随机固定」改成「随该区域自己的访问历史变」。

---

## 改了什么

**之前**（`terrain.py:132` 写着 fixed at birth）：
```python
self._decay_factor = 1.0 + rng.normal(0.0, decay_spread)   # 出生时随机，之后不变
```

**现在**（`assign()` 里）：
```python
self._decay_factor = 1.0 / (1.0 + float(self._assigned))
```

**`_assigned`** = 这个区域**累积被分配的次数的**（不是 `len(members)`——缓冲只有 64，会饱和）。

**效果**：
- **常来**（她常分配到这个区域）→ 因子小 → 恢复慢 → **记住**
- **不来**（从没分配）→ 因子 1.0 → 恢复快 → **忘掉**

---

## 为什么这是「局部化」

| | 之前 | 现在 |
|---|---|---|
| 参数是谁的 | **每个区域一个**（局部）✅ | **每个区域一个**（局部）✅ |
| 参数变不变 | **出生固定**（不变）❌ | **随该区域自己的访问历史变**（dynamic）✅ |

**Flow-Lenia 说的 `dynamic and localized`，两个都齐了。**

**而且是「不用我们拧」**——**每个区域的访问历史在拧它自己的因子**。

---

## 验证（副本）

```
区域 999 -> 1012
_decay_factor 分布: min 0.0007 / median 0.4277 / max 2.6399
```

**分布很宽**（0.0007 到 2.64）——**说明「常去的」和「不去的」确实分开了**。

**测试**：action 8/8、prefer_far 4/4、rest_energy 9/9、self_heal 2/2、stuck 6/6 **全过**。
