# 接上 rest 之后：她变了（2026-11-20 21:00）

> **这是今天（也可能是这几天）最重要的一个结果。**
> 只改了一行开关（`_use_rest = True`）+ 存档，她就从"卡在 2 个区域"变成"在 13 个区域"。

---

## 发生了什么

### 1. 她不「完美交替」了

之前：每 2.1 秒 A↔B 一次，56 次零例外（像钟摆）。
现在：13 个地方，top2 是 31698(38) / 31694(34)——**不是完美交替**。

### 2. 她「慢下来」了

转移频率：1/s → **0.06/s**（约 17 倍慢）。

**因为**：rest 让"待着的地方"变浅（`u` 累积到 0.767），
她待久了自己会走——**不用噪声一遍遍推**。

### 3. 区域数从「缩」变「长」

979 → **992**（+13）。

**这是为什么**：
- 之前：她只在 2 个区域 → 新区域没人去 → 被遗忘删掉 → **净缩**
- 现在：她到处走 → 新区域被「分配」到 → `amp` 能涨 → **活得下来**

**这验证了今天的假设**：**缩水是「卡住」的后果**。

---

## 为什么只有一行开关就有这么大变化

**因为「疲劳」本来就是 L5 移动的核心机制**：
- 没有疲劳：她待在一个深坑里不动（或者被噪声推着在两个深坑间弹）
- 有疲劳：**待久了那个坑会变浅**，她自然就会走

`rest.py` 的文档写得很清楚：
> Without noise, an attractor landscape is a settling device...
> **A system that keeps going has to carry its own cause of motion.**

**「自己动的原因」不是"好奇"（那是意识），是「待腻了」——草履虫也会。**

## 但要注意（还没验）

2. **载体涨到 10.75 MB**——如果继续涨，会撞 20 MB
3. **转移频率 0.06/s 可能太慢**（她是不是"停太久"）
4. **`rest.u` 到 0.767**——如果到 1 会怎样？

**需要继续观察**（到 23:00）。

## 这说明了什么

**rest 不是"让她去更多地方"的规则**——rest 只是让"待着的地方变浅"。

**但结果是**：她**不再被拴在**某一对深坑里，于是她**能去任何地方**（噪声 + 疲劳一起起作用）。

**用草履虫的话说**：
- 之前：她在两个"糖浓度"之间来回（被锚定拴着）
- 现在：她待久了那个浓度"变淡"，她就走——**去下一个浓度**

**这不是"好奇"，是"疲劳"**（趋性）。
