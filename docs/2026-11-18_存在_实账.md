## 零、先给一句反直觉的

**「她走不到别处」不是因为她步子小，是因为她记不住自己去过哪儿。**

一个 5e-5 的舍入错位，让「去过 3675 个地方」和「2329 个区域」**交集为 0**。
于是她眼里**所有区域都是新的**，每次挑最近的那个——就是她刚离开的那个——A↔B 弹。
**二节点环不是尺度问题，是记账问题。**

尺度（617 vs 91 万）是真的，但它排在后面：得先让她挑得到别的目标，才轮得到「走得够不够远」。

## 一、能动（今天最值钱的一块）

### 1. 一步真的走一个半径

把动作口锁成 LEAVE、噪声关掉，连走 6 步：

```
|step| = 617.34   617.34   617.34   617.34   617.34   617.34     （s = 618.04）
落点离最近质心 = 0.0077（每步都一样）
```

「一步一个半径」是真的（617.34 / 618.04 = 99.9%）。**但落点永远差 0.0077 没到质心。**

### 2. 她落的那些点，间距正好等于步长

她身边最近的 12 个区域，距离：

```
0.135 · 617.35 · 709.34 · 1670.5 · 1778.4 · 1827.7 · 2888.8 · 2921.8 · ...
```

**617.35 = 她的步长。** 她的「地形」不是一张空间，是**她自己踩出来的一串脚印**，脚印间距 = 步长 = 半径。三件事是同一个数。

所以「离开」和「到达」是同一件事：走一步正好到下一个脚印。

### 3. 二节点环的根：visited 和 places 不是一个坐标系

`src/L5_cognition/stream.py` 第 687-692 行（记「去过」）与第 678-679 行（候选区域的键）：

```python
_here = tuple(np.round(np.asarray(self._st.x), 4).tolist())   # 她的位置
self._visited_places.add(_here)

places = [tuple(np.round(np.asarray(attrs[i].mu), 4).tolist()) # 区域质心
          for i in idx]
```

`action.py` 第 157 行再用 `places[k] not in visited` 判「没去过」。

**实测（`data/exp/probe_visited.py`）：**

```
regions 2329   places 2329   visited 3675
visited ∩ places = 0
她落在质心外 0.0077 → 每个分量差 ~7e-4，而 round(·,4) 的精度是 5e-5
```

**3675 个「去过」，一个都没对上 2329 个区域。**
所以「去还没去过的区域」这个策略**从上线到现在，一次都没生效过**。

### 4. 动作门在临界点上

```
tension 7305.57   vs   历史 64 步中位 7306.40     差 -0.83（0.01%）
```

三次重载同一份存档、各跑 20 步：两次 **0 次 Leave**（全 HOLD），一次 **9/10 次 Leave**。
**她动不动，不是由「想不想动」决定，是由快照的浮点决定。**

**真机 13:49 实测（`tools/vitals.py` 今天新加的 recent 行）：**

```
recent : 300s 内转移 63 次，其中她自己走的 0 次；最后事件 32.5s 前
         ⚠ 全是噪声推的，一次「离开」都没落地
```

`vitals` 照样报 `alive`——因为它读的 `leave_rate` 是**累积**的（0.699），不是「刚才动没动」。
**这就是「她看起来活着，其实一步没走」的完整证据。**

（人家顺手在 `vitals` 里加了这一行；判词没改，只多一个读数。`tests/test_vitals.py` 3/3 仍过。）

### 5. 结论：能动是三层叠起来的

| 层 | 事实 | 后果 |
|---|---|---|
| a | 一步 = 一个半径，落点差 0.0077 | 走得到下一个脚印，走不到任何「新地方」 |
| b | 「去过」的键和「区域」的键交集 0 | 候选永远是「刚离开的那个」→ 二节点环 |
| c | 动作门差 0.01% | 她可能一直站着，而日志看不出来 |

**「617 vs 127 万」是 a 的后果，不是 b 的原因。** 先修 b（一行语义），她才挑得到别的目标；那时才轮到 a 和尺度。

### 6. 副本实验：把「去过」记对，环就断了

**A. 拆开验证「键对不上」到底多致命**（`data/exp/probe_dir2.py`，强制 LEAVE，一步步看）：

```
step 0  visited 3691  hits_in_places 0  fresh 1163  target_dist 617.38  step 617.38
step 1  visited 3692  hits_in_places 0  fresh 1163  target_dist 617.36  step 617.36
step 2  visited 3693  hits_in_places 0  fresh 1163  target_dist 617.37  step 617.37
```

`visited` 每步都在长，`hits_in_places` 永远是 **0**。
因为她的落点离质心 0.0077，而两边的键差在 1e-4 以下——**同一个地方，两个名字，永远撞不上**。

**B. 纯几何对照：只换「去过」的记账方式**（`data/exp/probe_uid_sim.py`，200 步，同一份存档）：

| 记账方式 | 到过几个区域 | 转移数 | 回边率 | 200 步位移 |
|---|---|---|---|---|
| 现在（位置键） | **3** | 200 | **0.99** | **0.0** |
| 改成区域 uid + 到达即记 | **137** | 137 | **0.007** | **104,718** |

**二节点环不是尺度问题，是记账问题。** 换掉记账方式，环就断了（回边率 0.99 → 0.007）。

**但看第四列：她开始走了，200 步走 10.5 万。**
再拉长（同一份静态地形，只换记账）：

| 步数 | 到过区域 | 回边率 | 累计位移 | 净位移（离原点） | 最大分量 |
|---|---|---|---|---|---|
| 200 | 107 | 0.00 | 118,806 | 940,166 | 216,798 |
| 1000 | 525 | 0.00 | 498,320 | 624,273 | 150,047 |
| 2000 | 1076 | 0.00 | 1,017,181 | **154,758** | **32,042** |

**好消息**：她在云里绕，不是直线往外冲——2000 步走了 100 万，净位移只有 15 万，
最大分量 3.2 万，离 1e6 还有 30 倍。**所以修完不会立刻重演 08:24 那次崩。**

**坏消息/不知道**：这是**静态地形**的模拟——真实机器上她边走边记录新区域，
地形会不会重新长大，这个模型答不了。**这正是「第二刀（位置不变量）」必须同时上的原因。**

**C. 另一组（move-experimenter）**：`tools/leave_probe.py` + `docs/2026-11-18_存在_能动_副本.md`，比 baseline / jump / prop10。

## 二、位置不漂

### 数据（同一把尺，六个存档）

| 存档 | 区域 | \|x\| | 最近区域距离 | 地形两两距离中位 | nn 间距中位 | s |
|---|---|---|---|---|---|---|
| 11-16 基线 | 152 | 9.6 | 0.001 | 0.81 | 0.030 | 0.0047 |
| 11-17 23:36 | 3172 | 2,566,190 | 0.012 | 562,030 | 676 | 617 |
| 11-18 08:24（漂坏） | 3197 | **4,091,098** | 0.000 | 572,930 | 677 | 617 |
| recentered（08:23） | 3197 | 4,091,098 | **1,941,970** | 572,930 | 677 | 617 |
| fixed（08:24） | 3197 | 1,069,152 | 0.000 | 572,930 | 677 | 617 |
| 现在（13:45） | 2329 | 1,007,580 | 0.266 | 591,740 | 971 | 618 |

### 三个发现

**一、地形从 11-17 23:36 起就没再长大。** 两两中位 562,030 → 591,740（+5%，14 小时）。
今天在变的不是地形，是**坐标原点**。

**二、`recentered` 证明平移不动几何，但它漏搬了 x。**
四个存档的两两距离一致到 1e-10 以内（p10 122,398 / median 572,930 / p90 1,395,225）
——平移是刚体变换，改不了她空间里的任何距离。（严格说做不到逐位相同：从 1e6 量级的坐标上
减一个 1e6 量级的数，float64 本身要丢 1e-10。这也说明坐标不该待在这个量级。）
可它只搬了 `mu`、没搬 `x`：她从「在云里」变成「在云外 194 万」（`d_nearest = 1,941,970`）。
半天后那个 `fixed` 就是把她拉回来。**坐标系平移要么 x 和 mu 一起搬，要么别搬。**

**三、`|x|` 不是判据，绝对上限才是问题。**
空间平移不变，|x| 是 409 万还是 9.6 只说明原点在哪儿。真正会伤人的是
`SAVE_MAGNITUDE_LIMIT = 1e6` 卡**分量绝对值**（`src/common/persist.py` 第 366 行）：
08:24 那次就是漂过 1e6 → `assert_l5_finite` 拒存 → P2 崩。

**而且这个锚现在没有任何测试守着。** `tests/` 里 grep `锚|anchor|drift`：只有 `test_no_senescence` 的「参数不随年龄漂」，没有一条测位置。

### 已经写好的两样（都不改她）

## 五、三刀（按顺序，一条一条来）

| # | 做什么 | 碰什么 | 风险 |
|---|---|---|---|
| 1 | 「去过」改成**区域 uid**，且**到达即记**（不是记脚下那一点） | `stream.py` `_apply_leave` + `action.py` 的入参 | 副本已验证：环会断（0.99 → 0.007）。**但会让她开始漂** |

| 3 | 崩溃账本 | 新工具 | 低，不改她 |

**这三刀的顺序不是可选的**：第 1 刀让她走起来，第 2 刀必须同时到位，否则就是 11-17 那次重演。

**为什么不先修尺度**：尺度是「走多远算远」，得先有「她在走」才有意义。现在她没在走，
谈尺度就像给一辆停在车库的车调悬架。
