| 层 | 只回答一个问题 |

## 2. 生命：机制齐，睡眠不通

**在的（六条）**

| 机制 | 实现 | 严格判断 |
|---|---|---|
| 趋性 | `rest.py` 疲劳场 | 在，且在动（u_mean 0.245，u_max 1.0） |
| 有限性 | `energy_burn` | 在，但耗电的参数是人定的 |
| 代谢 | `energy_recharge` | 在，参数人定 |
| 休眠 | `energy<=0 → asleep` | **在，但永不触发**（能量恒 1.0） |
| 稳态 | `homeostasis` | **只记录、不调节**——是观测，不是机制 |
| 意义生成 | `drive.tensions()` | 是张力场（286 条 / 和 1334.6），是**测量**，不是「意义」 |

**问题**

1. **睡不了**：充电 0.95e-6 > 平均耗电（约 0.55e-6）→ 能量贴 1.0，休眠路径不通
2. **三个数是我们定的**：耗电 1e-6、充电 0.95e-6、休眠阈值 0
3. **阶段记录会骗人**：`stage=4` 是 11-16 的历史记录，只升不降；她当前只在 2 个区域，和「成熟」的描述不符
4. 今晚修好两条「自己决定」的通道：活动耗电、活动决定遗忘（之前 `_action` 是整数、却和字符串 `"leave"` 比较，永远走错分支）

**结论：机制齐；睡眠不通；「意义生成」「稳态」名不副实（一个只是测量、一个只是记录）。**

## 3. 意识：3/5 有实现，GWT 数据上几乎不成立

**经验连续性（今晚归类修正后放这里）**

- 点火历史不落盘 → 重启后从空开始（**今晚已修**）
- 指代统计的分桶历史不落盘 → 重启后 64 步内标签是 `none`（**未修**）

**核心矛盾**：GWT 的判据是「超过她自己过去 90% 的峰值」，但她的峰值被 `ceiling=0.02` 压成常数 → 不点火；把 ceiling 调高，她又不动（0.02→位移 1.0；0.05/0.1/0.2→0.2，实测）。

**结论：3/5 有实现；GWT 数据上几乎不成立；AST 不在；经验不连续。**

## 4. 智慧：未开始，缺的是「移动」不是模块

**在的**：assign（改变形状）、`_decay_factor=1/(1+分配次数)`、merge、fold_to_capacity、graph（1,510 边）、identity（core 151 边）、recall、rehearsal（621 次，acc 0.9936）、grounding（897 键，H=5.3956 bits）

**阻碍**

1. **她只在 2 个区域间来回**：最后 500 次转移 `32434↔32435` 各 250 次，**90% 是噪声推的**
2. **一步被自己的 sigma 封顶**（2026-11-24 重测）：sigma 中位 151.53、邻区间距中位 619.4、双区距离 151.64 ≈ 半径和 151.53。但**冻结存档实验把两个假设都否掉了**：步长 ×1/3/4/5 只到 2/3/5/3 个区域；强制 far / 忽略 visited 只到 2/3 个（3 种子一致、区域数不爆）→ 卡点不在步长、也不在选择，**下一嫌疑是局部势阱太深**（那对区域 amp=0.02 顶着 ceiling，全群中位 0.0103，她被自己最深的坑按住）
3. **自我强化**：每处只待 1 步 → 待不腻 → 更不走远
4. **没有「学习」的度量**：形状在变，但没有任何量证明「形状被移动改变了」
5. 旧数要重量：`sigma` 中位现在是 151.58（11-18 是 618）

**结论：未开始。材料齐、判据缺；缺的不是模块，是移动。**
