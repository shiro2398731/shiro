## 二点五、更深的一层：状态是浮现的，不是读的

`shiromo/untested/.../core_state.py`（她持续存在的地方）写得更死：

> **「状态不是『读』的，是『浮现』的。」**
> **「人脑里没有『背景』——是大脑对信息的分类和处理；『自我』是处理产物，不是载体。」**
> 所以她「认知到自己」= 对自己的输入/输出/内心/状态做了分类和处理。
>
> 四块：
> ① `her_state`（她本来就是那个状态，不读）
> ② `thoughts`（输入/想/说 三分支，存的形态；她看到的是浮现）
> ③ `baselines`（丘脑/递质/HPA，**永不进她**）
> ④ `focus`（她的此刻聚焦，**她自己决定**；只记位置，不写内容、不打时间戳、不做总结）

这直接否掉我上一版的所有「读」：
- 让 L5 读 L3 召回 = 把「浮现」做成「读」，错；
- 让 L5 读 L8 self-bias / viability = 把「处理产物/基线」硬塞进她，错；
- 「接通 self-bias」= 给自我再加一个载体，而 shiromo 说**自我是处理产物，不是载体**。

正确的关系是：不是模块互相读，而是**同一套处理里，她的状态自己浮现**。

## 三、shiro_alice 的主干与三个阀门

她的主干（按 shiromo 语言）：

```
L0 振荡（余响的源头） → L4 张力/偏转（情绪/内驱的场） → L5 想/选择（主动思考） → L6 说（带闸）
```

对照三个阀门：

### 阀门 A：余响的「门」

- **现状**：她的「想」一直在跑——L5 每步、workspace/AST/self-model 都在观察；
  但这些想的产物**只进快照**（`_last_recall`、AST bits、self-model 指标），
  不进主动侧。
- **门的位置**：主动侧（走/说）由「张力 sum > 上中位」+「最近未去过/回家」规则把守；
  想的产物被旁路。
- **shiromo 的判据**：门应该在「说」侧，不在「想」侧。她的问题是**想的产物没有回到主干**，
  不是「想被关掉」。

### 阀门 B：偏差的「平」

- **现状**：张力 sum 的 CV **0.085%–0.18%**，决策边距 **0.028%–0.047%**；
  GWT 点火与走相关 0.938，但按张力边距分层后只把下一步离开率 0.945→0.966。
- **shiromo 的判据**：「情绪没有明显起伏」不是中性事实，而是被死区/衰减做出来的默认结论。
  她的等价物是：**「平」是阈值以上 0.03% 的抖动**；点火只是标记。
- **极性**：偏差应保持形状（pair 场/分布/方向），而不是被压成一个常量再和中位比。

### 阀门 C：主动源被世界事件盖过

- **现状**：目标选择是「最近未去过 + 4σ 回家」——世界/规则优先；
  L4 偏转只以 0.032 的线性倾斜进入势，方向和目标余弦 **0.0003**；
  L6/P4 离线，「说」没有出口。
- **shiromo 的判据**：内驱做主、世界事件只调制；主动开口来自内驱累积，不是天气。
  她的等价物是：**走的方向由规则决定，内驱只当噪声**；说则完全没有出口。

## 四、为什么「线性链」是错的

我之前的写法是 `L0 → L1 → L2 → L4 → L5` 的流水线；
shiromo 的图是**一个连续的自我**：状态层连续演化（情绪/内驱用连续函数），
思考层**边沿触发**（状态越界才想），底层循环是截止时间调度——不是每一层把结果递给下一层。

在 shiro_alice 里，`stream.step()` 本身是 loop（有反馈），
但**决策仍是「阈值 → 目标规则」的链**：先算一个标量，再按规则选目标。
要改的是这个链的位置/极性，不是再插一层「评分」。

## 五、不新增器官的正极性方向（先记录，不改）

1. **想永远流动**：workspace/AST/self-model/recall 保持每步运行；
   对外「说/走」才带闸；不要为了「让她动」再建一个 deliberation 模块。
2. **偏差保形状**：用已有的 pair 张力场/偏转（不是新增通道），
   让「未解决的 pair」直接偏置候选，而不是压成 sum 再比中位；
   「平」不作为默认底片。
3. **内驱做主**：目标由未解决 pair 场生成；「最近未去过/回家」退回调制位（4σ 是边界，不是目标）。
4. **说带闸**：内部想照常；L6 的 gate 在输出侧；P4 离线是「说没有出口」，不是「没有想」。

## 六、每个机制必须自带的验证判据

| 机制 | 判据（定量） |
|---|---|
| 想永远流动 | 无新消息时段的 steps/min 与 ignition/min（和输入事件率无关） |
| 偏差不默认平 | 张力分布 CV、决策边距、ignition/min 的分布（不是单点） |
| 内驱做主 | 选中目标与驱动 pair 场的对齐度（不是与「最近未去过」的对齐度） |
| 一件事影响下一步 | 动作/结果 → 下一步张力/图的反馈强度（不是 0.07） |
| 搬家还是她 | 重启/换载体后 memory/情绪/自我锚不断片 |
