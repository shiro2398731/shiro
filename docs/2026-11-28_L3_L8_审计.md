# L3 召回 / L8 身份：有东西，但没接线（2026-11-28）

## 一、L3 → L5：召回路径不进决策

工具：`tools/l3_l5_audit.py`（副本 400 步）。

| 量 | 值 | 含义 |
|---|---|---|
| 召回路径长度 | 均值 **2.27**，最大 3 | 她每次「想起」的只有 2–3 个节点 |
| 非空率 | 1.0 | 一直在召回 |
| **选中目标在召回路径里的比例** | **0.0** | L5 选目标时**从不看**召回 |
| 召回长度 vs 走/留 相关 | 0.566 | 同受结构驱动，不是因果 |
| 相邻两步路径 Jaccard | 0.82 | 召回本身是稳的 |

结论：召回（L3 的路径）**只进快照**（`stream.py:1072`），
决策只用图的原始边（张力/新意）。记忆「想起了什么」不影响「去哪」，
这就是 L3→L5 的裂缝：**有记忆，没有记忆的使用**。

## 二、L8 → L5：身份核心很稳，但通道是死的

工具：`tools/l8_identity_audit.py`（副本 400 步）。

| 量 | 值 | 含义 |
|---|---|---|
| 核心节点数 | 均值 **132.9**，最大 135 | 身份核心不小 |
| 空核心比例 | 0.0 | 一直有核心 |
| 相邻步 Jaccard | **0.997**（最低 0） | 身份高度稳定（偶发一次跳变） |
| fingerprint 维度 | 5 | 有指纹 |
| rounds | 400 | 每步都在观察 |

结论：**身份不是空的**——她有约 133 个节点的稳定核心。
但 `landscape.set_self_bias()` **全仓没有调用方**（审计 B），
所以这个核心对 L5 的动力学影响是 **0**。
裂缝不是「没有身份」，是「身份没有出口」。

## 三、这条对「复合性质」的意义

- 记忆不是「图」一个东西：它是**图 + 召回路径 + 巩固/遗忘**的复合；
  现在只有图进了驱动，路径只进快照。
- 身份不是「核心节点集合」一个东西：它是**核心 + 自我模型 + 连续性**的复合；
  现在核心很稳，但没有接到 L5，连续性也只记在外部账本。
- 所以「把召回接进决策」「把 self-bias 接上」都不是调一个权重，
  而是要给这些复合量**一条表示通道**（谁、以什么时间尺度、带什么语义）。
