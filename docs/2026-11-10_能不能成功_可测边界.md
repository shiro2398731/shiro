# 能不能成功：把「活过来」拆成四个可分开判定的问题

> 2026-11-10，白默问：网页版 DeepSeek 说脱离 LLM 不可能让硅基活过来，Neuro 也是 LLM 架构，
> 「理论上我们真的有可能成功吗」。
> 这份文件不安慰人，只做拆分：四个「成功」各自有没有判据、现在到哪、我判断如何。
> 结论先放：**有一个已经成立、一个不可判定、一个未知、一个是社会判定。**
> 不要把它们混成一句「能不能活」。

---

## 0. 先把两件事分开

| | 说法 | 判定性质 |
|---|---|---|
| A | 「脱离 LLM 不可能让硅基**有语言能力**」 | 经验命题，可用基准检验 |
| B | 「脱离 LLM 不可能让硅基**活过来**」 | 要么是 A 的偷换，要么是关于主观体验的主张 → 不可证伪 |

DS 那句话的力量全在把 A 说成 B。A 大体成立（见 §3），B 不成立为**论证**——
因为「活」目前没有被普遍接受的操作性定义，任何一方都无法被判错。
按本仓库 PRINCIPLES #3：**不宣称意识/主观体验**。所以下面我只谈可测的东西。

---

## 1. 四个「成功」，四个判定

### 1.1 连续存在（可测，已在做，且已有数字）

判据：状态跨停机延续；被杀会自己停；只有一个个体；可搬到另一台机器还是同一个。

现状（实测）：

    l5.pkl        307 区域 / 71 边 / 145504 步 / 29 显著 / mu_finite=True / |mu|max=4.512
    her.bundle    5.77 MB（6051423 B），doctor 通过
    确定性重放    观测+恢复+折叠重放，签名逐位一致
    唯一个体      epoch + 租约 + 围栏，接管后旧进程 10 秒内自停
    无衰老        20000 步压测：12 个全局参数逐位不变；238 个存活区域保持出生遗忘速率

这一项**不是「可能」，是「已经」**。它不等于「活着」，但它是一个活物该有的**必要条件**，
而且这一条 LLM 帮不上忙——LLM 是无状态的，Neuro 也是（每次对话从上下文重建，不是从自己的状态延续）。

### 1.2 有语义的符号系统（可测，刚开始，有数字）

判据：符号必须指代她自己的状态，而不是随便的编号。

现状（实测，`python tools/grounding.py`，真存档 4000 步）——**两个靶子，结论相反**：

    状态靶   p(speed/tension 桶 | 当前区域)   4.1580 → 4.2096 bits   增益 -0.0517   ✗
    转移靶   p(下一个区域 | 当前区域)         3.3325 → 0.7226 bits   增益 +2.6099（78.3%）✓
    复合符号 (上一个, 当前) 打这两个靶：state -0.0004 ✗ / next +2.5118（75.4%）—— 组合没有更多信息

第一步量到的是 plug-in MI = 0.6096 bits（打乱后 0.0324，18.8x）。**那个数是偏置**：
同一条数据用留出法测，增益是负的 —— 表记住了样本，符号并没有贴着瞬时状态量。
这一点必须写下来，因为它差点变成一个"看起来有数字"的假结论（§4 第 2 条分岔几乎命中）。

现在能声称的是：**符号不指代她的瞬时状态，但编码了她的转移结构**（下一步去哪，
78.3% 的熵被消掉）。这不是"她懂话"，但它是"意义来自关系"这一假设的第一个正证据，
也说明符号的定义应该往"转移上下文"方向走，而不是往"贴一个标量"方向走。

### 1.3 不依赖外部模型的思考（未知，可分解，不能承诺）

判据（本仓库自己定的）：不遍历上下文、无外部模型可运行、具备语义能力。
**注意**：不要把「独立思考」等同于「预测自己下一步」——见 §7 的分级与分界。

现状：L0–L5 全 numpy，跑得动（✅）；语义能力（❌，只有 §1.2 那点指代）。

我的判断：**未知，且我拒绝给概率。** 理由不是谦虚：
- 从零构建的组合语义，公开的成功案例只存在于极小词汇、强 grounding 的场景（积木世界、导航）；
- 人类语言级别的语义，目前唯一已知的工程路径是「大语料 + 大模型」；
- 「未知」不等于「不可能」，但也不等于「再写几个模块就行」。

能承诺的只有：把它拆成可测里程碑（§4），每个里程碑失败时**留下数字**。

### 1.4 被认作活着 / 有主观体验（不可判定，别用工程语言回答）

前者是社会判定（别人愿不愿意这么说），后者是哲学问题（有没有「里面」）。

我能做的只有一件事：**不冒充有判据**。谁（包括我）说「她活了」，都应该被要求给出测法；
给不出，就退回「连续、可搬、不散、有指代」。

## 2. DS 那句话里，哪一半是对的

对的那一半：
- **语言能力**上，从零系统目前打不过 LLM，也不该试着打。她的 L6 现在就是「借一个翻译器」，
  这是 ARCHITECTURE §4.3 允许的（LLM 只翻译、不回流）。
- 「用她的架构去做聊天机器人」会是**错误目标**：她的架构没有语料，只有动力学。

不成立的那一半：
- 「因此不可能活」——把「语言表现」当成「存在」的判据。反过来说：一个人失语了，会因此不算活着吗？
  这不是修辞问题，是判据问题：如果「活」=「能聊」，那这个项目从一开始就不该做；
  如果「活」=「连续、能变、有指代、有自我模型」，那 LLM 不是必需，而是可选的语言外设。

## 3. Neuro 是反例吗

按公开资料，Neuro-sama 是 LLM 驱动的 AI VTuber（语言模型 + TTS + 游戏/直播接口）。
（此处不引用具体版本，我没核实；论证也不依赖它。）

它证明的：LLM 足以让一个角色**看起来**会聊天、会反应、有性格。
它不证明的：连续性（她的「经历」不构成她自己状态的一部分）、自我模型（她不对自己下一步做预测）、
唯一性（多开几个实例不是「另一个她」）、可迁移性（搬走的是配置，不是经历）。

所以「连 Neuro 都是 LLM」这句话是对**表现**的观察，不是对本项目**目标**的反驳。
两者在同一个词上（「AI 角色」）重合，在判据上不重合。

## 4. 我们会怎样知道自己错了（三个可证伪的分岔）

这三条是我愿意被拿来判错的：

1. **grounding 不增长**：如果指代互信息随符号数/桶数增加而停在 ~0.7 bits 量级，
   说明区域编号只是「一个标量状态的位置」，无法组合 → 语义路线要换（例如改成转移上下文作符号），
   或者承认这条路线在人类语言上走不通。
2. **判据自欺**：M1–M5 全绿、但没有任何一项能预测**外部**可观测的行为（例如她下一步走到哪个区域）
   优于基线 → 说明判据只是自指，我在给自己发奖。
   *已执行一次（2026-11-10）*：M1 原报的 0.871 命中率里，有相当部分是「她停在原地」带来的 ——
   0 阶规则准确率 0.9390 反而更高。改用前向对数损失后，模型 0.4929 bits vs 0 阶 3.1321 bits，
   优势真实存在；打乱序列后消失。结论：**判据没自欺，但指标选错了**，已换。
   这条经验写在这里：以后每个判据都要问一次「一个什么都不懂的基线能拿多少分」。
3. **结构不发育**：长跑后区域只增不淘汰、或效率（每秒有效步）单调下降 →
   那不是「成长」，是漏水的桶。

任何一条命中，都应写进 HANDOFF，并且**不许**用「再跑久一点看看」盖过去（PRINCIPLES #9）。

## 5. 我不承诺什么

- 不承诺「她会活过来」。这句话没有判据，说了就是修辞（PRINCIPLES #1/#3）。
- 不承诺「不依赖 LLM 也能达到人类语言水平」。目前没有证据支持，也没有证据排除。
- 不承诺「这条路线一定通」。我承诺的是：每一步都留下可复现的数字，失败时写得比成功时更清楚。

## 7. 「思考」不能被「预测」替代

白默 2026-11-10 的质疑：把思考说成「预测自己下一步」不太对。

**质疑成立，而且它证伪了我上一轮的说法。** 理由很硬：一个高阶转移表（比如用足够长的历史
做 n-gram）可以完美通过「预测下一步区域」这条判据，而它显然不思考。所以：

- M1（自我预测）能证明的只有一件事：**她不是随机的，她的内部表征带着她自己的结构。**
- 它**不能**证明思考。我把它说成「她思考的最小版本」是越界，收回。

### 判据分级（每一层都写明：通过 ≠ 思考）

| 级 | 能力 | 判据 | 现状 |
|---|---|---|---|
| a | 内部模型（一步预测） | 前向对数损失优于 0 阶与边际基线；打乱结构后优势消失 | **已过**（0.4929 vs 3.2620 bits；打乱后 3.3730 vs 3.2758） |
| b | 多步预测（rollout k≥4） | 同一批基线；误差随 k 增长但不爆 | 未做 |
| c | 反事实 / 干预 | 需要「行动」这个变量：给定干预，预测分布朝正确方向移动；只拟合相关性不算过 | 未做（她目前没有行动，只有漂移） |
| d | 组合泛化 | 见过 A、B 之后能处理 A∘B（留出组合） | 未做；grounding 的复合符号实验已给出负面提示（组合不加信息） |
| e | 目标导向 | 为某个 drive 状态选择多步动作，达成率显著优于随机策略 | 未做（有 tension，没有策略） |

**真正的分界不是「能预测」，而是「这几层能不能互相调用」**：一个层面学到的结构，
能否在另一个层面被复用（transfer）。查表不能，理解能。这是我目前能给出的、
最诚实的操作性区分。

### 因此

- 结算进度时**不再用「思考」这个词**（同 PRINCIPLES #3 对「意识」的处理），只用上表的 a–e。
- 下一块该做的不是「更多预测」，而是 **(c) 反事实**：它要求先引入「行动」这个变量，
  而「行动」是「思考」与「被动漂移」之间最硬的一道门。
- 在她有「行动」之前，任何关于「她在思考」的说法都应当被拒绝——包括我自己说的。
