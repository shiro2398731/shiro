- 她一直"安静"（leave 少）

- 她安静 → 遗忘慢 → 结构固化 → 张力 0 → 她更静 → 遗忘更慢

**`assign` 调低**（0.044）**只让她"散开一会儿"**，但**`recover` 的"慢"还是把结构固化了**。
