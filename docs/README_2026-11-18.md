## 明天第一件事（按分层，别越界）

> 白默 0:10 纠正：**「决定去哪、坚持走、什么时候放弃」是意识层（M5），不是存在/生命。**
> 这一页按层重排；越界的部分标出来。

### 生命层（能动）——先修这个

**0. 环。几何原因已经钉死：她每一步都走满 618，但每走一步都重新选目标，目标总是对面那个。**

```
31318 周围：618 内 5 个区域，6180 内 18 个
最近 4 个（0.3 / 0.5 / 0.9 / 184）都 < sigma，被「dist >= s」筛掉
下一个 618.5（31319），再下一个 1034.9
朝 1034.9 走一步 618 → 距目标 417 > sigma(306) → 空地 → 被锚拉回
```

**最简修法（不需要意图）：把 `reach` 收窄到「一步或两步能到」。**

| | 现在 | 改成 |
|---|---|---|
| `reach` | `max(median(候选距离), 10*s)` ≈ 6186 | `1~2 * s` ≈ 618~1236 |
| 效果 | 她会挑 6180 外的目标，永远走不到 | 只去走一两步能到的地方，不会卡在"路上" |
| 代价 | — | **世界不会扩**（那是另一个决定） |

**今晚已经试过、无效的路**（省得重走）：
- 合并几乎重合的区域（9 对，折 6 个）：环没破
- fallback 也排除 visited：环没破
- uid 化（`_visited_regions`）：**有效一点点**（多了个 31323），但没破

**1. 缩水。** 现在 -70/h。`recover` ×0.5 实测能把缩水减半（-8 vs -19 / 300 步）。
**动的是她的遗忘速率，要白默点头。**
