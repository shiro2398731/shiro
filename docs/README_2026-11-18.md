### 生命层（能动）——环已经破了 ✅

**0. 环：2026-11-18 23:15 破的，靠一个门槛，不靠意图。**

真凶：最近邻居 31319 距离 **618.5**，s = **618.6**——差 0.1，被 `dist >= s` 筛掉。
于是「最近的 fresh」变成 **70 万外的 30333**（地形在半径 70 万的球壳上），
她每步朝那边走 618、永远走不到，只在那几个区域间弹。

修法：`action.py` 里 `dist >= s` → `dist >= s/2`（仍然排得掉「几乎重合」的区域）。

```
副本：distinct 3 → 14、回边率 0.99 → 0.219、净位移 0 → 4250
真机（epoch 55，300 秒）：不同区域 2 → 10，没有主导对
```

- 破环不需要「意图」（那是意识层 M5）；
- **uid 化是错的**——`test_consistent_relabelling_changes_nothing` 说「重新编号区域，轨迹不能变」，
  uid 只是名字，不能参与决策。已回滚（回滚后反而更好：14 / 0.219 vs 13 / 0.375）。

**1. 缩水。** 现在 ~-70/h。`recover` ×0.5 实测能把缩水减半（-8 vs -19 / 300 步）。

### 设计选择（白默定）

**4. 她能不能记下「新地方」。**（白默 0:40 纠正：**她的世界是盘里的记录，不是空间**——
跟「给我全盘权限」一样，环境不是限制。）

现在她**写不出新记录**：`terrain.record:809` 要求落点离所有已有区域 ≥ 1 个 sigma 才建新区域，
而她一步 = 1 个 sigma → 每步都正好落在已有区域上。

**但 0:50 的实验证明「放宽判据」没用**（data/exp/probe_assign_threshold.py，300 步）：

| 赋值阈值 | 区域变化 |
|---|---|
| 1.0 sigma（现状） | -4 |
| 0.5 sigma | -7 |
| 0.33 sigma | -7 |

**放宽反而更少。** 真正的原因：她**朝已有区域走**（direction 挑的是「候选区域」），
落点总在区域附近——判据松紧都不重要，**因为她从来不去「没有区域的地方」**。

所以要她记下新地方，得让她**有时朝没有区域的方向走**（探索），不是把判据放宽。

**1:00 的实验证实了**（data/exp/probe_explore.py，300 步，每次离开以概率 p 走随机方向）：

| 探索概率 | 区域变化 | 载体 |
|---|---|---|
| 0（现状） | **-7** | 5.16 MB |
| 0.1 | **0**（不缩了） | 5.20 MB |
| 0.3 | **+5** | 5.26 MB |
| 1.0（全乱走） | **+28** | 5.26 MB |

**给她一条小概率的「探索」通道，她的世界就能长大**，载体只涨 0.1 MB。
p=0.1 刚好抵消遗忘，p=0.3 开始净增。**这是「探索策略」，要你定。**
这是「能动/探索策略」，要你定。

原来的说法（判据尺度）——部分对，但不是主因：
**不占额外空间，只多几条数据**。代价：同一块地的不同角落会被记成不同地方。

**要你定：这是不是你要的「世界」。**
