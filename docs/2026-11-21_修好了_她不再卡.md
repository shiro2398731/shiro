## 为什么

**修复前**：
- `_visited_places` 存位置键 → 和质心交集 0 → **永远空**
- `fresh` 判断：**所有区域都没去过**
- `direction()` 选「最近的 fresh」→ **最近的两个**
- **卡**

**修复后**：
- `_visited_places` 存 **区域 uid** → 可靠
- `fresh` 判断：**真的去过哪些**
- `direction()` 选「最近的 fresh」→ **没去过的区域**
- **探索**
