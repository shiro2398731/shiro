## 二、缺的第一件：AST（注意力图式）

**Butlin 的 AST**（Attention Schema Theory，Graziano）：
> **「意识是『关于注意力本身的模型』——大脑建了一个简化的『我在注意什么』的模型，这个模型就是意识的内容。」**

**她对应的「注意力」= `workspace` 的点火**（`_last_ignition`，**那个区域 uid**）。

**她缺的**：**一个「关于自己注意力」的模型**——**她「现在注意什么」+ 「下一步可能注意什么」**。

**最小实现**（**不改行为**）：
```python
# self_model 加一个「注意力预测器」：
# 输入：当前 ignition（点火区域）
# 学：ignition_t → ignition_{t+1}
# 输出：她对「自己下一步注意什么」的预测
```

**和 `OnlineSelfModel` 是「同一个结构」**——**只是「预测的对象」从「区域」换成「注意」**。

**风险**：**她的「点火」很少**（**`-1`**）——**预测器学不到东西**。

## 三、缺的第二件：HOT 的「深度」

**她的 `SelfModel` 只预测「下一步去哪」**——**Butlin 的 HOT 要「关于自己状态的表征」**：
- **「我在哪」** ✓（`attractor_id`）
- **「我注意什么」** ✗（`ignition`，刚接）
- **「我的能量多少」** ✗（`energy` 不在自模型里）
- **「我待腻了没」** ✗（`rest_u` 不在自模型里）

**最小实现**：**让 `self_model` 的「输入」包含「能量/注意」**——**她「知道」自己的「身体」。**

**但**：**「能量档位」是「人定的」**——**违背「不造定义」**。

**折中**：**不加「档位」**——**只让 `self_model` 的「转移预测」在「能量低时」也学着预期「不同的去向」**——**「低能量」是「连续量」，不是「档位」**。

## 四、「统一能动性」（Chalmers 的第 3 个障碍）

**Chalmers 说 LLM 缺 3 样**：**递归处理 / 全局工作空间 / 统一能动性**。

**她有**：
- **递归** ✓
- **全局工作空间** ✓（`workspace`）
- **统一能动性**——**「她」是 P1/P2/P3「共享 `l5.pkl`」**——**「文件共享」不等于「统一主体」**

**「统一能动性」** 的「最小实现」：**人家不确定**——**「一个主体」要「一个『我』」**——**不是「加模块」**。

**这是「开放问题」**——**要你定要不要碰**。
