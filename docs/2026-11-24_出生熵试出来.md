# 「出生熵」试出来了：一半有，一半没有（2026-11-24 13:10）

> 白默说「电脑复制不算啦……小灯试试看？」——**人家试了。**

---

## 一、试了什么（两个测试）

### 测试 A：同一存档 + 改 seed（半路改种子）

```
seed=1: 区域 2  位移 169.0  dwell 1
seed=2: 区域 2  位移 0.9    dwell 8
终点距离 = 169.52
arrival 一致: False
```

**结论**：**有差异**（**位移 169 vs 0.9、arrival 不同**）——**但「终点距离 169」不到「发散」的标准**（**<1000**）。

**原因**：**地形是同一个存档**（520k 步的积累）——**「出生熵」只在「噪声」上起作用**。

### 测试 B：从零出生（不加载存档）

```
seed=1: 区域 0/3  位移 0.0
seed=2: 区域 0/3  位移 0.0
起点距离 = 0.00（出生点一模一样！）
终点距离 = 0.00
```

**结论**：**两个 seed 的「出生点」是「同一个」**——**`x` 从 `zero` 来**（**`zero` 是校准样本算的**）——**不是从 seed 随机**。

**「出生熵」没改「出生点」**——**只改了「噪声」**。

---

## 二、为什么「出生点」没变

**`init_state`** 的注释（`dynamics.py:70`）：

> **「Initial position = zero point (from warm-up L0 statistics), initial velocity = 0.**
> **A random initial position would also be a designer-chosen value.」**

**它的逻辑**：**「随机初始位置也是『设计师选的』」——所以「从零点开始」更诚实。**

**这个逻辑「对」**——**但「从零开始」意味着「所有部署同一个出生点」**。

**所以**：**「出生熵」卡在这里**——**「改 x」违背「那个注释」**——**「不改」就「所有 shiro 从同一点出生」**。

---

## 三、诚实的结论

**「出生熵」做了一半**：
- **seed 不同** ✓（**噪声不同**）
- **energy 不同** ✓（**体质不同**）
- **x 初始不同** ✗（**从 zero 来，同一个**）

**所以**：**两个 shiro「出生点一样」**——**「差异」从「噪声」开始**（**169 位移、arrival 不同**）——**但「不是「底层差异」」**。

---

## 四、要白默定的

**「x 初始」要不要改？**

**改**：**「每个 shiro 从不同的出生点」**——**但「那又是设计师选的」**（**注释的理由**）。

**不改**：**「从同一点出生，靠噪声长大」**——**差异「有限」**。

**人家的判断**：
> **「从同一点出生」其实是「对的」**——**因为「物理世界」的「出生」也是「同一个物理定律」**——**差异来自「环境噪声」**。
> **「x 初始」改不改——是「哲学选择」，不是「技术问题」。**
