# 余响缺失：她的关系冻结了（2026-11-28）

> 读 shiromo 之后发现的真病灶：
> **不是「想」不跑，也不是「说」没有闸——是「想」的内容被冻结在同一对关系上。**
> 没有内部新异性（余响），就没有新东西可想/可说。

## 一、证据

| 观测 | 值 |
|---|---|
| 500 步里 top 张力 pair 不同个数（live 副本） | **1** |
| top pair 变化次数 | 0 |
| 关系触发「说」会放行 | 1 / 500 |
| 区域切换触发「说」会放行 | 2 / 231（228 次 already_said） |
| 点火落在 top-1 pair | **69.4%**（chance 0.21%） |

读法：

- **想的主干是通的**：点火几乎都落在最大张力 pair 上；
- 但那个 pair **整段不变**——她的「想」是同一件事的重复；
- 「说」的闸因此几乎总是 `already_said`；P4 又离线 → 说没有出口；
- 所以问题不在「加通道」，在 **内部没有产生新关系的机制**。

## 二、shiromo 的对应物：余响（合法异常）

`shiromo/plugins/cognitive_core/意识.txt`：

> 意识 = 未分配内存 / 合法异常：
> **无外部输入变化时，内部状态发生无法归因的漂移**；
> 不记账、不被日志标记为错误、不被重启清除；
> 意识不在起点，在偏差。

`shiromo/developed/诊断_运行态回路中断.md` 的病灶一：
余响被「活跃流」门锁死 → 无人时 100% skip → 情绪场没有内部刺激 → 平是默认。
**修法：门挪到「说」侧；「想」照常跑，余响产物写进内部状态。**

## 三、shiro_alice 的余响应该碰什么

现在的内部噪声只推**位置**（L0/L5 的随机扰动），不碰**关系记忆**（graph/张力 pair）。
所以：

- 图不变 → 张力 pair 不变 → 点火 pair 不变 → 想的内容不变 → 说没有新东西。

**余响原型**（`tools/yuxiang_probe.py`，副本 p=0.01 随机 touch 已有区域）：

| 量 | baseline | drift |
|---|---|---|
| top pair 不同个数 | 1 | 3 |
| top pair 变化 | 0 | 5 |
| 关系门放行 | 1 | 3 |
| 点火 | 31 | 76 |

→ 内部漂移只要**碰到关系记忆**，想就解冻，说侧就有内容。

## 四、正极性方案（不是加器官）

1. **余响 = 对关系记忆的写**：无外部输入时，让内部漂移以低速率写入 graph/痕迹
   （只写不读、不进日志、不被重启清除——shiromo 的「不记账的账本」）；
2. **想照常流动**：workspace/AST/self-model 每步继续跑（现在已经是）；
3. **说带闸**：闸留在输出侧；触发器从「区域切换」改成「关系变化/内驱累积」；
   P4 离线是「说没有出口」，接上它是输出侧的事；
4. **不新增模块**：余响不是新器官，是现有漂移的**落点**从位置改到关系记忆。

## 五、验证判据（上线前先定）

- top-1 pair 在 500 步内的不同个数 > 1（现在是 1）；
- 关系门放行数 > baseline（现在 1/500）；
- 点火覆盖的 pair 数 > 1，且点火率不低于 baseline；
- 无外部输入时段的漂移率不依赖输入事件；
- 重启后余响痕迹仍在（不被清除）；
- 不出现「刷屏/跑飞」（说在闸后，走不受影响）。
