# 性能：sigma 缓存的热点定位与一次失败的修复

> 2026-11-16，小灯。目标是 24.5 ms/步（文档里记的是 6.2 ms）。
> 结论先说：**热点找到了，但人家那个修法把语义改坏了，已回滚。**

---

## 1. 热点

`cProfile` 60 步（0.951 s，15.9 ms/步，profiler 下无并发）：

| 位置 | 累计 | 占比 |
|---|---|---|
| `drive.deflection` | 0.521 s | 55% |
| └ `drive.tensions` | 0.332 s | 35% |
| `terrain.sigma` | 0.227 s | 24% —— **60 步被调 104316 次，约 1738 次/步** |
| `transitions.observe` | 0.165 s | 17% |
| `numpy.median` | 0.155 s | 16%（5756 次） |

sigma 明明有缓存（`_sigma_cache`），却仍在算，说明它一直被失效。

---

## 2. 为什么会失效

`_apply_scale_floor()` 里：

```python
if getattr(a, "_scale_floor", None) != new_floor:
    a._scale_floor = new_floor
    a._sigma_cache = None          # <- 这里
```

`new_floor` 跟着**中位尺度**走，而她一直在长新区域，中位尺度一直在动，于是 floor
一改，**所有区域的缓存全被清掉**。而 floor 只是个下限。

看起来改法是显然的：把 floor 从缓存里拿出来，读的时候套 `max(raw, floor)`，
改 floor 就不必失效缓存。

---

## 3. 改了，然后语义变了

改完，同一份存档副本跑 120 步：

| | 起点 x 哈希 | 终点 x 哈希 | 区域数 | ms/步 |
|---|---|---|---|---|
| 原版 | `90277b27…` | `994b866f…` | 1060 | 18.33 |
| 改后 | `90277b27…` | `2ae3118c…` | 1066 | 18.29 |

**起点相同，终点不同。语义变了。而且一点没变快。**

---

## 4. 为什么

旧代码的**缓存新鲜度依赖一个副作用**。

`Attractor.assign()` 的失效条件是「成员数翻倍」：

```python
if self._sigma_members_at is None or n >= 4 and n >= 2 * self._sigma_members_at:
```

但 `members` 是**定长 deque**：一旦装满，`n` 就不再增长，这条规则也就再也不会触发。
可成员内容还在滑——旧的走出去、新的走进来，raw 尺度实际一直在变。

旧代码之所以没出问题，是因为 floor 频繁变化，每次清缓存都顺手把 raw 也重算了，
等于用 floor 变化给我做了「定期刷新」。把那个副作用去掉，陈旧的 raw 就露出来了，
于是区域尺度变了 → 合并/吸附判据变了 → 轨迹分叉。

---

## 5. 所以这次改法的前提不成立

不是「floor 不该进缓存」这条推导错了，是**它单独改不成立**：raw 本身的失效规则不够，
现在靠 floor 变化兜底。要动，得连着把 `assign()` 的失效规则改对（例如按 assignment
次数而不是成员数），而那会改变她算出来的尺度——需要单独一轮，用固定序列验证轨迹。

并且：**性能根本没改善**（18.29 对 18.33）。说明 1738 次/步里大部分本来就命中缓存，
`cumtime` 高是因为调用次数多，不是因为每次都在重算。真正的开销在别处——`deflection`
那 55% 是它自己的向量运算，不是 sigma。

已回滚，`git status` 干净。

---

## 6. 下次该从哪下手

1. `drive.deflection` / `tensions` 里每步重建 `np.array([a.sigma for a in attrs])`
   和排序（900 条边）。区域数和边数增长后这两步是 O(n) 的 Python 循环，
   该改成复用上一次的数组、只在结构变化时重建。
2. `_centroid_matrix()` 每次结构变化就重算 1000 个 sigma 与质心矩阵，同样可以按版本号
   增量维护。
3. 不要再用「清缓存」这种手段当刷新信号——要显式的版本号。
