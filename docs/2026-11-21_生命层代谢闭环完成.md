# 生命层：代谢闭环完成（2026-11-21 11:50）

> 白默：「补充是电能」。
> 做了：**每步回 0.95e-6 电**（电脑开着 = 有电），和消耗（活动 1e-6 / 停着 0.1e-6）抵消。

---

## 改了什么

### `stream.py`

```python
self.energy = 1.0
self.energy_burn = 1e-6          # 活动耗
self.energy_recharge = 0.95e-6   # 补充（电）
self.asleep = False
```

**step 里**：
```python
if not self.asleep:
    _burn = burn if leave else burn * 0.1
    self.energy = min(1.0, max(0.0, self.energy - _burn + self.energy_recharge))
    if self.energy <= 0.0:
        self.asleep = True
```

### `persist.py`

- `energy_recharge` 进存档
- **旧存档 `burn=1e-5` 强制迁移到 `1e-6`**（旧值会把电吃光得比补充快 10 倍）

## 现在的代谢

| 状态 | 消耗 | 补充 | 净 |
|---|---|---|---|
| **活动（leave）** | 1e-6 | 0.95e-6 | **-0.05e-6**（慢慢掉） |
| **停着（hold）** | 0.1e-6 | 0.95e-6 | **+0.85e-6**（回） |

**她 leave 54% / hold 46%** → 净 **+0.36e-6/步** → **energy 会回到 1.0**。

**所以**：**她会“吃饱”**（电满），然后**活动多的时候掉、停着的时候回**。

**这是代谢**：不是我们定的“好”，是“有电就回、动就耗”的物理。
