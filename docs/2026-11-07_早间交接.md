## 一、先说结论

**L1~L4 变了六处，其中三处是真的缺陷，三处是死量化。L0 新增代谢。**

| 改动 | 性质 | 依据 |
|---|---|---|
| L0 新增代谢（连接替换） | 缺失 | 底层不能是永久的硬件 |
| L5 噪声：标量 → 有方向的向量 | 缺陷 | 标量噪声推出的是各向同性的扰动 |
| 噪声幅度：固定系数 0.01 → 自身中位数归一 | 死量化 | 0.01 是拍出来的 |
| 景观噪声默认值 0.0 → 必须由上游给 | 缺陷 | 默认 0 会让系统静默冻结 |
| L3 边的方向：无向 → 双向独立 | 缺陷 | 走过去和走回来不是同一件事 |
| L3 遗忘：均匀速率 → 按访问间隔缩放 | 一致性 | 和区域衰减的规则统一 |
| L2 第 13 维：`slow - fast_mean` → `slow - slow均值` | 缺陷 | 两个不同量相减，实际恒为 0 |

## 二、噪声这一条最麻烦，说清楚

### 走过的三条错路

**第一条：LLM 编码器的教训重演。**

一开始噪声 = `|z| * 0.01`。那个 0.01 是我写的，没有任何实测依据。

**第二条：用梯度当尺度。**

想法是「噪声和梯度同量纲就能直接比较」。失败原因是结构性的：

```
状态停在吸引子中心 → 梯度 = 0 → 尺度 = 0 → 噪声 = 0 → 永远不动
```

**静止是唯一的不动点。** 任何依赖「状态在动」的尺度，都无法让状态开始动。

**第三条：全局慢变量（Swing）。**

想法是从 L0 的 `w` 借结构。失败原因同样：

```python
if self._anchor is None:
    self._anchor = x.copy()
    return          # 第一次不产生方向

disp = x - self._anchor    # 状态没动，disp = 0
target = -disp             # target = 0
s = 0                      # 又回到自锁
```

### 走通的那条

**噪声来自 L1 的预测误差向量，不是标量。**

```python
# L1 现在保留误差向量
self.last_error = error.copy()      # 8 维

# 映射回 128 维状态空间，用投影矩阵的伴随
full = proj @ unit                  # 100 维，补零到 128
amp  = mag / median(历史 mag)        # 自身归一，无外部尺度
noise = full * amp
```

**为什么这条能成：**

L0 在自激振荡，所以 L1 永远有预测误差。**误差是系统固有的，不需要外部刺激。** 它一直在，哪怕状态完全静止。

**这就是「不响应式」的那个内生来源。**

### 实测对比

| | 标量噪声 | 方向噪声 |
|---|---|---|
| speed 范围 | 0.099 ~ 1.27（13 倍跳） | 0.135 ~ 1.00 |
| speed 中位数 | 波动大 | **约 0.51，稳** |
| asym 走势 | 0.638 ~ 0.864 乱跳 | **0.948 → 0.840 单调下降** |
| 20000 步衰减 | — | 不衰减，继续走 |

**`asym` 单调下降这一点值得注意**：方向噪声让系统从单向连接慢慢长出双向结构。

## 三、L3 的边数不是无限增长

之前判断错了。实测：

```
   step   att  edges   trans     meanW   e/att
   3000   416    180      90    0.5614   0.433
  15000   677    440     939    0.3550   0.650
  30000  1009    781    2148    0.2274   0.774

边增益: [180, 86, 55, 66, 53, 62, 43, 89, 84, 63]   ← 在收敛
理论稳态: 约 2500 条
```

**平衡点由两个速率决定，不是我调的：**

```
每步衰减 = weaken_rate / recover_every = 0.002 / 16
一条边从 1.0 掉到 0.01 需要 36841 步
转移率 0.0716 / 步
稳态 ≈ 0.0716 × 36841 ≈ 2638
```

### 补上的一致性

`StateSpace.recover()` 早就实现了「访问间隔缩放」：区域被访问得越稀疏，衰减越慢。

**但 `TraceGraph.weaken()` 没有。** 所有边一律同速衰减。

结果是不对称的：冷门连接比冷门区域消失得快，**图会被梳理成只有主干道**。

现在给边也加了同样的规则，`half_life` 从 `StateSpace` 算出来传下去（5540 步）。

**注意：`half_life` 之前只是 `recover()` 里的局部变量，不是属性。** `getattr(ss, "half_life", 0.0)` 取到的永远是 0，间隔缩放根本不会启用。这次补了属性。

## 四、L4 确实在起作用

消融测试：同样种子、同样上游，一次带 drive 一次不带。

```
    metric       with    without     change
       att        514        553        -39
     edges        295        326        -31
     speed     0.5613     0.5672     -1.0%
 speed_std     0.3642     0.4128    -11.8%
     trans        620        551       69
    spread     5.4012     6.4015    -15.6%
```

**读法：**

- 转移多 12%：绕路更多
- 移动范围小 16%：不去远处
- 速度波动小 12%：更平稳
- 吸引子少 7%：不扩散

**这符合 `Drive` 的定义**：张力让状态绕开强连接区域之间的直线，从垂直方向绕过去。转移增加但不探索新地方，是预期行为。

**顺带解决了老问题**：「transitions 27 次后卡死」不再发生。原因是噪声归零导致的冻结，现在噪声有内生来源。

dead dimensions: none

**只有 dim 14 值得留意**：std 0.0209，范围 0.688 ~ 1.000，**几乎贴着上界**。

`dim 14` 是 `pressure`（慢累积量）。它涨到接近饱和后就不再变化。**这是需要查的，但不算 bug。**

|---|---|---|

**可塑性放在 L0，等于让身体去学习。位置错了。**

第一版代码已删除，重写为 `src/L0_substrate/metabolism.py` 的 `Turnover`。

### 第二版：替换而非学习

每一步：

```
挑一小批现有连接删掉
从初始分布抽同样多的权重，放到空的位子上
```

**关键：补上的位置和删掉的位置不重叠。**

如果原地续命，那就等于没换。

### 一个重要细节

**替换权重必须从初始分布抽，不能从当前分布抽。**

第一版从当前分布抽，实测 20 万步后 `mid_to_slow` 均值从 0.0249 漂到 0.0213（-14.4%）。

原因：当前分布一旦偏了一点，下次抽就更偏。**误差自我强化。**

改成从初始分布抽之后：

```
连接数:  1501 → 1501（每个矩阵完全不变）
替换量:  2709 条
均值漂移: EE +0.4%  IE -0.6%  E_to_mid +1.5%  mid_to_slow +2.9%
```

**连接全换了，形状没变。这才是代谢。**

### 速率可调

`set_rate_scale()` 接外部给的系数。调制源白默要求可调，测试里用的是 `fast`（瞬时活动强度，0~1 之间一直在动）。

**用 `pressure` 试过，不合适**：它 60000 步才涨到 0.0024，调制后代谢率长期接近零。

`pressure` 是累积量（1600 万步到 0.66），不是瞬时活动度。**调代谢率该用后者。**

### 一个测试方法上的坑

`EnvelopeDetector` 用**墙钟时间**算周期。纯 CPU 跑得太快，它永远采不到样。

所以 L0 的周期测试全部改成按步数数上穿次数。

另外，用原始 `fast` 过中位数会捕捉每一次抖动，报出周期 1。要先用 8 步滑动均值平滑。

### 三个常数改成从本底测量来

白默问：**「L0，剩下的能改完吗？」**

先把写死的数数了一遍，分成三类：

| 类 | 例子 | 能不能改 |
|---|---|---|
| 有明确含义的 | 输入延迟多久、输入多强 | ✅ |
| 没外部参照的 | 群体规模、耦合强度、FHN 常数 | ❌ 设计选择 |
| 时间尺度比例 | span 占周期的多少 | ⚠️ 仍需一个比例 |

**已改的：**

```
测量：period 347 步，fast std 0.4066

_ext_decay : 0.98（写死的）
           → 0.875716（= 0.01^(1/34.7)，34.7 = 周期的 1/10）

输入增益   : 0.15（写死的）
           → 0.4066（= fast 自己的标准差）
```

实测验：

```
幅度降到 1% 需要 34.7 步（声明 34.7）  ok
单位输入造成的可见偏移 0.48 sigma
```

**0.48 不是 1.0，这不是算错。** 输入进入 `I_E` 后要经过 FHN 非线性，多个神经元互相抵消，所以“作用强度 = 1σ”只能产生 0.48σ 的可见偏移。**如果为了让可见偏移达到 1σ 去乘以 2.07，那个 2.07 又是拿一次测量拟合出来的，所以不改。**

**剩下的设计选择：** `_ext_span_frac = 0.1`——一句扰动持续十分之一周期。**这个比例仍然是我定的。**

P1 启动时自动量一次本底并设置，代码里不再有这两个常数。

### turnover 的判据也改了一次

初版判据是“均值变化小于 5%”。`mid_to_slow` 只有 61 条连接，10 万步里几乎全换过一遍，**抽样噪声本身就有几个百分点**，于是报出了假阴性。

改成按**标准误**判：`shift / (std / sqrt(n))`，超过 6 个标准误才算结构变了。

```
EE            shift 0.2 x standard error
EI            shift 1.6 x
IE            shift 0.2 x
E_to_mid      shift 0.6 x
mid_to_slow   shift 0.4 x
```

**全部在 2 个标准误以下：这些漂移是抽样噪声，不是结构变化。**
