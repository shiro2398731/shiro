## 这个方向的边界（诚实）

**现在改的还是「我们写的公式」**：
```python
_target = 0.002 * (0.5 + act)      # 这个 0.5 是我们定的
_ar_target = 0.05 * (1.6 - density) # 这个 1.6 是我们定的
```

**真正彻底的「独立自立」应该是**：
- **不使用"我们写的公式"**
- **`recover_rate` 直接等于"她自己测出来的量"**（比如"最近被删区域的比例"）

**人家还没到那一步。** 但现在**至少是「她的活动在调参数」，不是「我们定的常数」**。
