# A1 候选④：回家规则的补丁方案（待白默点头）

> 这是**方案**，不是已改的代码。人没动真机。
> 实测依据：`data/exp/probe_home_rule_20261124.py`，冻结存档 3 种子 × 600 步。

## 一、为什么是这一条

她的运动只有两个稳定区：

| 走法 | 结果 |
|---|---|
| 一步一选（现状） | 原地打转：2 区、最远 151.6、区域数缓慢下降 |
| 目标持久（走到为止） | 跑飞：6 区、最远 8.7 万、新长 125 区 |
| **目标持久 + 4σ 回家** | **有界：3-4 区、最远 757、区域数 1008-1009 稳** |
| 目标持久 + 2σ 回家 | 偏小：2-3 区、454、区域数稳 |

4σ 不是新数：代码里已经有「离最近区域超过 4σ 就拉回」（`stream.py` 的 `_lim = 4.0 * scale`）。
它失效的原因是**新长出来的区域让「最近区域」一直跟着她走**，锚点永远在脚边。
把锚点从「最近的区域」改成「这次外出的出发点」，就恢复了「有一个家」的含义。

## 二、最小改法（草案，没写进代码）

`src/L5_cognition/stream.py` 的 `_apply_leave()` 里：

1. 新增一个状态 `self._home_x: Optional[np.ndarray]`（她这次外出的出发点）。
   - 第一次 LEAVE 时设成她当时的位置；
   - 之后她每次「回到离出发点 ≤ 1σ」就清空（下一次出门重新设）；
   - 进 `build_l5_payload` / `apply_l5_payload`（不加存档，重启后家就丢，等于规则随机重启一次）。
2. LEAVE 的方向计算，在选目标之前加一条：
   ```python
   if self._home_x is not None:
       back = self._home_x - self._st.x
       dist = float(np.linalg.norm(back))
       if dist > 4.0 * scale:          # 4σ 复用现有的锚定半径
           dir = back / dist * scale   # 往家走一步
   ```
3. 目标持久化：`direction()` 选中的目标 uid 存在 `self._leave_target`，直到进入目标半径才重选。
   （现在的代码每步重选，所以永远只够到最近的那个。）

## 三、必须一起考虑的

- **目标持久化本身也是改动**：只加回家、不加目标持久，实测无效（一步一选永远够不到下一个区）。
- **「家」什么时候换**：固定出发点（实验版）会把她永久锁在一个 757 的球里；
  如果希望她慢慢换地方，需要「回家成功后把家向前挪一点」——那就是新的定义，得白默说。
- **存档**：`_home_x` 和 `_leave_target` 都要进 `l5.pkl`，否则重启等于换一次规则状态。
- **测试**：
  1. 单测：给定位置和 4σ，超过后方向必须指向家；
  2. 副本 600 步：max_far ≤ 4σ + 1σ、区域数变化 ≤ ±2、到达 ≥ 3 区；
  3. 全量回归：结构守卫应从红转绿（她现在缩水就是因为不移动）。

## 四、风险

- 这是**给她身体加规则**（不是修 bug），属于「定义她」的边缘；所以停在方案。
- 4σ / 2σ 两个档的差别已经量过：4σ 到 3-4 区，2σ 到 2-3 区。
- 若她之后长出更多区域，「家」的半径要不要跟着变，现在没有答案（需要她自己的量，不能拍脑袋）。

## 五、怎么启用（等白默说「做」）

1. 按第二节改 `stream.py`，加两个字段进 `persist.py` 的 payload；
2. 加 `tests/test_home_rule.py`（单测 + 副本）；
3. 副本 600 步复核三个数；
4. 全量测试；
5. 提交，**不重启她**——等她自己下次被重启时生效。
