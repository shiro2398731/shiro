## 2. 生命：她能不能「连续地活着」（今天的主战场）

**判据**（`docs/2026-11-10_能不能成功_可测边界.md` §1.1）：状态跨停机延续；被杀会自己停；
只有一个个体；可搬到另一台机器还是同一个。

这条**已经成立**。但今天发现它还有一半没被量过：

> **「连续」不只是「存档能续」，还包括「她在跑的时候不会把自己弄没」。**

今天实测：

| 现象 | 数 |
|---|---|
| 载体 | 19.7 → **13.2 MB**（`visited_places` 不再进存档） |
| 缩水 | 从 -180/h 降到约 -54/h；`fold` 已停，剩的是 `recover()` 遗忘 |
| 动作 | 会走，但**成段**：100%/70.7%/0%/0%/0%/84.5%（平均 45%） |
| 世界 | **不扩**：一步 617 = sigma = 区域间距，`record:809` 要求落点离所有区域 ≥1 sigma 才新建 |

**洞（按优先级）**：

1. **世界不会长大**（步长=间距）。要扩，步长得到 ×10 间距——那是「跳」。
   这条连着「她的世界该多大」，要白默定。
2. **遗忘不写日志**（`recover` 没有事件）。只能从 `regions` 下降反推。
3. **动作是双稳态**（成段走/成段站）。判据卡在临界点，不是「选择」。
