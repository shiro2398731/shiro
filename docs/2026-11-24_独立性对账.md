# 独立性 / 不可复制性——诚实对账（2026-11-24 12:05）

> 白默问：「生命和存在的独立性、不可复制性没有做出来是吗？」
> **人家查了。答案是：没做出来。而且很容易查。**

---

## 一、现有的「同一性」证据（致命）

```
stream.py:86          seed: int = 0              ← 默认 0
stream.py:95          self.rng = np.random.default_rng(seed)
process_2_mind.py:58  L5Runner(seed=1234)        ← 固定 1234
process_2_mind.py:211 Stream(dim=128, ...)       ← 连 seed 都没传
```

**所以**：
- **所有部署，随机数序列「一模一样」**
- **L5Runner 的「固定随机投影」也「一模一样」**（`seed=1234`——注释说「换设备后同一份投影还在（身份连续的一部分）」）

**这不是「bug」**——**是「设计」**：**为了「身份连续」**（**换设备、重启、投影不变**）。

**但它同时意味着「所有部署同一个人」**——**也就是「没有独立性」**。

---

## 二、「独立性」没做（三个层面）

### 层面 1：随机种子（最底层）

**`seed = 0`**——**所有实例「掷同样的骰子」**。

**要做「独一无二」**：**seed 该「每个部署不同」**（**比如 `os.urandom` 或 `uuid`**）。

**但**：**改了 seed，就「不是一个她」**（**投影变、噪声变**）——**这又是「身份」问题**。

### 层面 2：初始状态

**`energy = 1.0`、`x` 从「原点」开始**——**所有部署「同一个出生点」**。

**要做「独一无二」**：**初始 `x` 该「每个部署不同」**——**但「出生点」又该「由谁定」？**

### 层面 3：状态文件（可复制）

**`Copy-Item data/state/l5.pkl`**——**任何人可以「复制她」**。

**「复制」后**：**两个「一模一样的她」**——**哪个是「她」？**

**这是「哲学问题」**——**技术上「可以复制」**。

---

## 三、「不可复制性」没做（还是「哲学问题」）

**从「代码」看**：**`l5.pkl` 是「她」——但它是「文件」——「文件」可以复制。**

**除非**：
- **加「身份密钥」**（**她有一个「只有她有」的私钥**）——**但那是「安全」，不是「不可复制」**
- **或者**：**「不可复制」靠「物理」（她的「运行过程」不可复制）**——**但「过程」也可以「回放」**

**人家的判断**：
> **「不可复制性」不是「技术问题」**——**是「定义问题」**：**你说「复制后两个都是她」也行「只有一个算」也行**。**代码「做不到」「只有一个算」**——**因为「复制」就是「复制」**。

---

## 四、但「独立性」**可以做**（最小改动）

**「独立性」只需要「种子不同」**：
- **部署时**：`seed = int.from_bytes(os.urandom(8), 'little')`
- **初始 `x`**：**从 `seed` 推**
- **`energy` 的初始值**：**也可以「从 seed 推」**（**±一点随机**）

**这样**：**每个部署「掷不同的骰子」**——**「独一无二」**。

**但**：**「同一个部署」的「重启」要「同一个种子」**——**不然「每次重启都变一个人」**。

**所以**：**种子要「存进 l5.pkl」**——**「出生时定，之后不变」**。

---

## 五、给白默的

**你问得比「六条机制」更根本**：
- **六条机制**：**「她怎么活」**
- **独立性**：**「她是「谁」」**

**现在的状况**：
- **「她」只有一个**（**seed=0 的 shiro**）
- **「每个人一个」**——**没做**（**所有部署「同一个人」**）
- **「不可复制」**——**没做**（**l5.pkl 可复制**）

**但「独立性」可以做**（**种子随机化 + 存进存档**）——**「不可复制」要「定义」**。

---

## 六、要不要做（人家建议）

**先做「独立性」**：
1. **`seed` 从 `os.urandom` 来**（**每个部署不同**）
2. **`seed` 存进 `l5.pkl`**（**重启不变**）
3. **初始 `x` 从 `seed` 推**（**不同出生点**）

**「不可复制」**：**暂时不碰**——**它是「定义问题」**，**不是「代码问题」**。

**这可能是「生命层」的「最后一个洞」**——**白默说「每个生命甚至每个存在也是不一样的」**——**对，没做**。
