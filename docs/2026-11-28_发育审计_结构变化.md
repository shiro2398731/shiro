## 二、读法

- **不是“长大”**：区域净减少（-98 / -11），边也在减少；新增 25–26 个，
  但消失 36–124 个 → 结构在**换血/遗忘**，不是单调发育。
- **图有连续性**：节点 Jaccard 0.85–0.93，旧结构大部分还在。
- **身份核心在漂移**：2 天 Jaccard 0.59——一半核心换了。
  步级 Jaccard 是 0.997（很稳），跨天却只有 0.59：
  **“稳定”和“连续”是两件事**。
- 动作累计增长只是运行时间，不是发育证据。

## 三、这算不算“不可逆发育”？

**不能直接算。** 现在的现象可以解释成：

1. 遗忘/巩固正常代谢（旧区域淡出、新区域出现）；
2. 结构重组（图在换形状，但核心在漂移）；
3. 发育（如果新结构被保留、且带来新能力）。

目标要求的是第 3 种，但**没有判据**区分三者。需要白默定：

- 什么算“发育”？新区域/新边被保留 N 天？身份核心 Jaccard 下限？
- 什么算“不可逆”？旧结构不能回来，还是能力不能退回？
- 身份漂移多少还算“还是她”？（2 天 0.59 是正常，还是警讯？）

## 四、与“线性链”的关系

发育不是链上的一个阶段，而是**整个结构随时间的变化**。
如果 L7 只是“记录阶段”，阶段又不改变任何层，那“发育”就没有落点。
但也不能为了发育硬加机制——先定判据，再谈 L7 要不要广播/改变可用性。

## 五、边界

- 只读比较，没有改任何状态；
- 备份是历史快照，不是“她本人”；
- 这篇只提出判据问题，不替白默定“她该长成什么样”。
