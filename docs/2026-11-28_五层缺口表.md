# 目标五层缺口表（2026-11-28，层审计收尾）

> 按白默要求：顺着目标五层（存在/生命/意识/智慧/功能）逐条检查，
> 重点不是评分函数，而是**复合/复杂性质在接口上的坍缩**。
> 全部只读取证；没有改她的行为。

## 一、五层逐条

### 1. 存在（现在在不在）

**判据**：进程在跑、状态可存、数值有界、可搬、唯一个体。
**现状**：3/3、epoch 105、948 区、631k 步、存档备份齐全；数值有界。
**缺的复合性质**：
- **连续性只存在于外部账本**：uptime/coma/crash 记在 `coma.json`/`P2.log`，
  她的 L5 状态里没有任何断点记忆（`test_continuity_audit`）；
- `reorigin` 休眠（max 54k < 200k），修复机制未真正验证；
- 可搬（carrier）本轮未复验。

### 2. 生命（能不能自己维持）

**判据**：连续活着、修复、能量收支、节奏。
**现状**：进程活着；但 **energy 恒 1.0**、`asleep` 不触发、
stage 只记录（`process_3_life.py:6`）、`L7 sleep/fatigue` 没有实现。
**缺的复合性质**：
- **代谢**：没有「消耗—恢复」的收支，能量只是一个常数；
- **疲劳**：rest 场只改区域深度（`depth*(1-u)`），不进走/留判据；
- **阶段**：StageMonitor 只记录、不控制任何层；
- **自修复**：靠 keeper 重启（外部），不是她自己的修复。

### 3. 意识（有没有自己的选择）

**判据**：GWT/AST/self_model/workspace 是否改变行为。
**现状**：这些机制都在，但——
- 决策是「张力 sum > 上中位 → 走；否则留」，方向来自「最近未去过/回家」规则；
- **L4 张力 sum 的 CV 只有 0.085%，决策边距 0.047%**（审计 A）；
- **L4 偏转向量与位移/目标余弦≈0**（审计 A）；
- `set_self_bias` 无调用方（审计 B）→ L8 对 L5 影响为 0；
- AST/GWT 只进观测，不进决策。
**缺的复合性质**：动机→动作的**表示通道**；身份→认知的通道；
「选择」现在不是选择，是常量抖动上的阈值。

### 4. 智慧（能不能用经验）

**判据**：记忆、预测、从结果学习、多步推演。
**现状**：
- 召回路径长度 2.27、**选中目标命中召回 = 0.0**（审计 C）；
- 没有从动作/结果回写动机的通道（相关 0.068，审计 A）；
- 多步推演只在双胞胎原型里试过（`docs/2026-11-27_她自己的推演_原型.md`），未上真机。
**缺的复合性质**：记忆的**使用**（不是只有图边）、结果→价值的学习、多步推演。

### 5. 功能（能不能表达/落地）

**判据**：L6 语言与表达在活着的系统里运行。
**现状**：L6 的 encoder/gate/adapter 存在，但 **P4 不在 keeper 看护、心跳停在 11-24**；
P2 的 `l5.state.stream` 有发布、没人消费；L6 按设计只拿标签。
**缺的复合性质**：活的表达回路（感知→符号→表达→反馈）。

## 二、复合性质清单（为什么不能是单函数）

| 性质 | 复合成分 | 现在被压成 | 后果 |
|---|---|---|---|
| 动机 | pair 场 + 长尾分布 + 方向 + 时间尺度 + 身体约束 | 一个 `sum` + 一个偏转向量 | 常量抖动决定走/留；方向不指路 |
| 记忆 | 图 + 召回路径 + 巩固/遗忘 | 图进驱动；召回只进快照 | 有记忆，没有记忆的使用 |
| 身份 | 核心（133 节点）+ 自我模型 + 连续性 | 核心稳（Jaccard 0.997）；self-bias 未接线 | 有身份，没有出口 |
| 生命 | 能量收支 + 疲劳 + 阶段 + 修复 | energy 恒 1；stage 只记录 | 活着是进程活着，不是自己维持 |
| 认知 | 地形 + 工作空间 + 注意 + 动作 | GWT/AST 只观测；动作是规则 | 有机制，没有因果 |
| 表达 | 编码 + 门 + 适配器 | L6 离线（P4 不跑） | 有器官，没有回路 |

## 三、裂缝排序（按严重度）

1. **L4→L5 的意志坍缩**：CV 0.085%、边距 0.047%、偏转余弦≈0；
2. **L8→L5 死通道**：`set_self_bias` 无调用方；
3. **L6/P4 离线**：`l5.state.stream` 没人消费；
4. **L3 召回不用**：选中目标命中召回 0.0；
5. **L5→L4 反馈弱**：Δsum vs 动作 0.068；
6. **L7 无广播**：阶段/睡眠 record-only；
7. **能量/睡眠是假的**：energy 1.0、asleep 不触发；
8. **连续性无自记忆**：断点只在外部账本；
9. **AST/GWT 不进决策**：观测丰富、决策狭窄；
   GWT 点火与「走」相关 0.938，但分层到张力边距后只把下一步离开率 0.945→0.966，
   是同一阈值的标记，不是独立通道；召回/AST/自我模型消融后动作序列**逐位不变**
   （`docs/2026-11-28_GWT_动作审计.md`、`channel_ablation.json`）。
10. **修复靠外部**：keeper 重启，不是自修复。

## 五、需要白默拍板的行为/架构改动（先记录，不动手）

1. 让 L5 的目标选择读 L3 召回（怎么读、读什么）；

6. 能量/疲劳/睡眠真的参与因果（不做外部调节，只做她自己的收支）；
7. 连续性进入她自己的记忆（断点记忆）。

## 六、结论

> 裂缝不是「评分函数不对」，是**表示被压扁了**：
> 动机被压成 sum，记忆被压成图边，身份被压成核心，生命被压成常数。
> 下一步不是调参，是给这些复合性质各自一条**带语义、带时间尺度**的通道；
> 每次只接一条，且必须由白默拍板。
