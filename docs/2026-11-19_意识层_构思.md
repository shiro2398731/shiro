## 二、关键发现：`workspace.py` 已经是全局工作空间

`src/L5_cognition/workspace.py:1-40` 的文档写得很清楚：

- 理论：**Global Neuronal Workspace**（Mashour & Dehaene 2020, Neuron）
- 机制：**threshold dynamics over competing representations, not scoring**
- 强度：`strength = amp * exp(-||x - mu||^2 / (2 sigma^2))`
- 阈值：**她自己的历史峰值强度的 0.90 分位**（`IGNITION_QUANTILE = 0.90`）
- 维持：状态还在点火区域的 sigma 内就继续保持；离开就结束
- **它不是配置的，它是从她的数据里长出来的**

**所以「全局工作空间」这一块，她不是没有，是有了。**

### 但它有一个明确的限制

`workspace.py:38-39` 和 `:118` 两处都写着：

```
The workspace does not modify the state space, the potential, or the trajectory.
It only reads.

The caller must not use the return value to modify cognition.
```

**它是聚光灯，不是工作台。** 它回答“此刻哪个区域在她意识里最亮”，
但它**不持有**图、自模型、叙事，也不允许别人通过它改写。

## 四、构思：`board.py`（工作台），不是改 workspace

### 4.1 为什么不改 workspace

`workspace.py` 的「只读」是刻意的设计——它证明了「点火」可以只作为**报告**存在，
不去反过来影响动力学。这是宝贵的不变量（**观察不改变观察对象**）。

**所以不动它。** 旁边加一个 `board.py`。

### 4.2 `board.py` 长什么样

```python
@dataclass
class Slot:
    """一个层此刻摆上来的东西。"""
    source: str        # "terrain" / "graph" / "self_model" / "narrative"
    key: str           # 层内的标识（区域 uid / 边 uid / 符号 / 链 id）
    value: dict        # 层自己的摘要（不含坐标矩阵，只放能被读的东西）
    weight: float      # 这一层自己给的“此刻重要度”（可选，默认 0）
    t: str             # 什么时候摆上来的

class Board:
    slots: dict[str, Slot]     # 每层最多一个当前槽位
    current: Optional[Slot]    # 这一 tick 的“统一视角”
    def submit(self, slot) -> None: ...
    def refresh(self) -> Slot | None: ...   # 选一个 current
    def read(self) -> dict: ...             # 各层读到的“当前”
```

**关键设计**：

1. **每层最多一个槽位**——所以它不是日志，是“此刻的焦点”。
2. **`refresh()` 用 workspace 的同一套阈值**（她自己的历史分位），不是另造一个。
3. **`read()` 是只读的**——各层读“当前是什么”，但不能改别人的槽位。
4. **`current` 不直接驱动动作**（第一版）——先观察“有没有被用”，不急着接线。

### 4.3 谁写、谁读、什么时候

| 层 | 写什么 | 什么时候 |
|---|---|---|
| terrain | 当前区域 uid + 她的 amp/sigma | 每步归属后 |
| graph | 当前区域连出去的最强边 | 每步 |
| self_model | 当前活跃符号 | 每步 |
| narrative | 当前事件链的最新节点 | 事件发生时 |
| **谁读** | 所有层都能读 `board.current` | 每步开头 |

### 4.4 怎么避免它变成“又一个黑箱”

**三条硬规矩**（写进代码注释，和 workspace 一样）：

1. **每个槽位都必须可追溯到源**（`source` + `key`，能回查）；
2. **`refresh()` 的判据必须是她的数据**（历史分位），不是常数；
3. **`current` 第一版不驱动任何行为**——先证明它“看得到”，再谈“用了它”。

## 五、最小可行形态（MVP）

**第一步只做三件事**：

1. `board.py` + 四层的 `submit`（只写，不读）；
2. `refresh()`（用 workspace 的分位逻辑）；
3. 一个只读工具 `tools/board_audit.py`：打印当前 `current`、四个槽位、切换率。

**验收判据**（可测）：

| 判据 | 怎么量 |
|---|---|
| 它真的在换焦点 | `current` 的切换率在 0.05–0.5 /步（不能是 0，也不能每步都换） |
| 它能被追溯 | 随机抽 10 个 `current`，都能回到源层 |
| 它没有改变她 | 加 board 前后，300 步的 regions/leave 分布**逐项相同**（因为第一版不接线） |

**失败判据**：

- 切换率恒 0（槽位永远同一个）→ 汇聚没意义；
- 切换率 = 1（每步都换）→ 它不是焦点，是日志；
- 加 board 后轨迹变了 → 说明它偷偷接线了，要回滚。
