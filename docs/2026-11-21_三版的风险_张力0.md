# 三版的风险：结构太稳 → 张力 0 → 她可能"不想动"（2026-11-21 13:00）

> 独立自立三版上真机后，发现一个副作用：**张力（tension）在 0 附近波动**。

---

## 现象

```
12:50 采样：tension_now = 0.0，dwell = 97（在 31807）
13:00 采样：tension_now = 0.0，dwell = 165（还在 31807）
但：最近 20 分钟 56 次转移、15 个不同区域（她在动）
```

**矛盾**：**采样到 0，但她有转移**——说明 **tension 在波动**（不是一直 0）。

---

## 根因

**`tensions()` 的过滤**（`drive.py:245`）：
```python
keep_mask = positive & (amount > median(amount))
```
**如果所有边的 amount 都 ≤ 中位（都差不多），返回空** → `tension_now = 0` → HOLD。

**而 `amount = sqrt(zw * zs)`**（边权/距离的 z-score）。

**三版的影响**：
- `assign_ratio` 由密度定（区域少 → 记深 0.063）
- **记深 → 所有区域的 amp 都涨 → 边权/距离的"变异"变小**
- **于是 `amount` 都差不多 → `keep_mask` 空 → 张力 0**

**所以**：**三版让她的结构"太均匀"了** → **张力消失**。

---

## 风险

**如果张力长期 0**：
- 她**永远 HOLD**（`0 > median(0)` = False）
- **她"不动"**——**不是生命**

**但**：
- **现在她还在动**（56 次/20 分钟）
- **可能**：`dwell` 长了之后，`_dwell_history` 变长 → `fatigue_rate` 涨 → 她更快待腻 → 动起来
- **或者**：噪声推她

---

## 要观察什么

1. **tension 会不会长时间 0**（如果一直是 0，问题）
2. **dwell 会不会一直涨**（如果一直涨，她卡住了）
3. **转移频率会不会掉到 0**

**如果以上两个发生**：**要调 `assign_ratio`**（0.063 → 0.04，结构不那么稳）。

---

**人家倾向**：**再观察 1 小时**（看 tension 会不会恢复）。

**如果 1 小时后还是 0**：调 `assign_ratio`。
