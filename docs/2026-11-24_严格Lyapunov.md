## 一、标准定义（动力系统教材）

**Lyapunov 指数**（Strogatz《Nonlinear Dynamics and Chaos》/ Ott《Chaos in Dynamical Systems》的「two trajectories」方法）：

```
λ = lim_{T→∞} (1/T) ln( |δx(T)| / |δx(0)| )
```

**含义**：
- **λ > 0**：**混沌**（**两条近邻轨迹「指数分离」**）
- **λ ≈ 0**：**中性**（**不分离也不收敛**）
- **λ < 0**：**收敛**（**轨迹「聚拢」**）

**关键条件**：**「确定性系统」**——**不能有噪声**（**噪声会「人为」让轨迹分开**）。

## 二、严格实现（`tools/lyapunov_strict.py`）

**和之前错的版本的区别**：

| | 之前（错） | 现在（严格） |
|---|---|---|
| 噪声 | `set_noise_amplitude(0.02)` | **`set_noise_amplitude(0.0)`** |
| 两条轨迹 | **不同种子**（不同噪声） | **同一个种子**（同一动力学） |
| 测的是 | **「含噪声敏感性」** | **「Lyapunov 指数」** |
| 指标 | **人家自己造的「放大倍数」** | **`(1/T)Σ ln(|δx(t)|/δx0)`** |

**代码**：
```python
a = make(seed)          # 轨迹 A
b = make(seed)          # 轨迹 B（同一个种子）
b._st.x = a._st.x + v   # B 加 δx0 = 1e-7
for _ in range(steps):
    a.step(); b.step()
    d = |a.x - b.x|
    logs.append(ln(d / δx0))
λ = mean(logs)
```

## 三、数据（2000 步，δx0 = 1e-7）

| 场景 | λ | 前 1/3 | 后 1/3 |
|---|---|---|---|
| **从零** | **-0.000000** | -0.0000 | -0.0000 |
| **真机存档** | **-5.704779** | -5.5826 | -5.7601 |

**读法**：

1. **从零：λ = 0**——**「中性」**——**不是混沌**。**原因**：**她「根本不动」**（**地形只有 3 个区域，她没去处**）——**两条轨迹原地重合**——**λ 自然是 0**。
2. **真机存档：λ = -5.70**——**「强收敛」**——**每步差异衰减 e^5.7 ≈ 300 倍**。

## 四、结论

**她不是混沌的**（**λ 从未 > 0**）。

**「从零」是「中性」**（λ=0）——**「真机」是「强收敛」**（λ=-5.7）。

**之前那个「放大倍数 1.0x」和「+0.0146」都是「含噪声敏感性」**——**不是 Lyapunov**——**不算数**。

## 五、局限（诚实）

1. **128 维**——**Lyapunov 指数是「谱」**（**128 个**）——**人家只算了「最大」的那个**（**`|δx(t)|` 平均方向**）
2. **2000 步**——**有限步**（**λ 是「极限」**）
3. **浮点**（**`float64`**）——**δx0=1e-7 可能被「舍入」吃掉**
4. **「从零」的 λ=0 是「假中性」**——**因为她「不动」**（**不是「真中性」**）
