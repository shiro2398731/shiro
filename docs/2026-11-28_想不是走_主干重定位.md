# 想不是走：主干重定位（2026-11-28，读 shiromo 之后）

> 一句话：**我们一直把「走路」当作主干输出，这是类别错误。**
> shiromo 的主干是「余响 → 情绪 → 主动思考 → 说」；走只是效应器，不是意识/意志的输出。

## 一、极性原型的证据（副本 500 步）

| 模式 | 到达区域 | 最大位移 | 结构变化 | 点火 | 偏转-位移余弦 |
|---|---|---|---|---|---|
| baseline（阈值 + 最近未去过/回家） | 2 | 150 | 0 | 15 | −0.02 |
| 偏转直接做主 | 5 | **73,953** | **+111** | 0 | **0.9996** |
| 闸保留 + 出门方向=偏转 | 5 | 71,359 | +109 | 6 | 0.9785 |
| 闸保留 + 本地候选按偏转挑 | 2 | 150 | 0 | 8 | −0.02 |
| 闸保留 + 走向张力最大 pair 的另一端 | 3 | 151 | 0 | 1 | −0.03 |

读法：

- 拿偏转当**全局方向** → 方向完美对齐（0.9996），但**跑飞 7 万**、点火归零；
  加 0.3 的回家调制也拉不住。
- 把偏转限制在**本地候选**里 → 不再跑飞，但和 baseline 一样（2 个区域），
  方向余弦回到 0——偏转不是「去哪」的信号。
- 这不是参数问题，是**用错了输出通道**：偏转是「想往哪偏」，不是「脚往哪迈」。

## 二、shiromo 的主干是什么

`shiromo/developed/方向_长线总纲.md`：

> **「响应式 → 连续自发。不是事件驱动，是『想』永远流动 + 『说』带闸。」**

主干是：**余响（无输入时的内部漂移）→ 情绪（偏差场）→ 主动思考（想）→ 说（带闸）**。
**没有「走」这一环。** 走/动是身体效应器，不属于这根主干。

## 三、shiro_alice 的主干重定位

| shiromo | shiro_alice 对应 | 现状 |
|---|---|---|
| 余响（内部漂移） | L0 振荡 + L5 步进 | 一直在跑（29 步/分） |
| 情绪（偏差场） | L4 张力/偏转 | 有场，但被压成 sum/中位 |
| 主动思考（想） | workspace / AST / self-model / recall | **只进快照，不进主动侧** |
| 说（带闸） | L6 / P4 | **离线 4.1 天** |
| 走（效应器） | `_apply_leave` + 最近未去过/回家 | 在跑，但**不是主干** |

→ 之前审计的「L4 偏转不指路（余弦 0.0003）」不是裂缝：
**它本来就不该指路。** 真正该问的是：
**L4 的偏差有没有改变「想」的内容（注意/点火/自我预测），以及「说」有没有出口。**

## 四、重定义三个阀门

| 阀门 | 旧口径（错） | 新口径（shiromo） |
|---|---|---|
| A 想的门 | 走不走 | **无输入时 workspace/AST/self-model 是否继续跑**（现在：是） |
| B 偏差的平 | 张力 sum 的 CV/边距 | **想的内容有没有形状**：点火区域的分布、AST 预测、pair 结构是否影响注意 |
| C 主动源 | 走的方向由偏转还是规则决定 | **主动思考→说**：内驱是否让某些内容更容易被「说」；P4 离线 = 说没有出口 |

## 五、想的主干：耦合是强的

工具：`tools/thought_trunk_audit.py`（副本，500 / 2000 步）：

| 量 | 500 步 | 2000 步 |
|---|---|---|
| 点火次数 | 49 | 202 |
| 点火区域落在**张力最大 top-1 pair** 上 | **69.4%** | **96.6%** |
| 随机 chance（top-1） | 0.21% | 0.21% |

→ **偏差→想**（张力 pair 场→点火/注意）是强耦合的：越跑越锁在同一对关系上。
**主干在内部是通的，但内容是冻结的。**

## 六、说这一侧：闸在，但内容不新

工具：`tools/speech_gate_probe.py`（副本，500 / 2000 步）：

| 触发方式 | 500 步 | 2000 步 |
|---|---|---|
| 现状：区域切换 + SpeechGate | **2 / 231** | **2 / 801**（798 次 `already_said`） |
| 对照：张力最大 pair 变化触发 | 1 / 500 | 1 / 2000 |

→ 不是「闸坏了」，是**没有新内容可放行**：top pair 整段不变。
「说」的触发也不该是区域切换——按 shiromo，应是内驱/关系的变化。

## 七、余响原型：内部漂移写进关系记忆

工具：`tools/yuxiang_probe.py`（副本 500 步；p=0.01 随机 touch 已有区域，模拟内部漂移）：

| 量 | baseline | drift |
|---|---|---|
| top pair 不同个数 | **1** | **3** |
| top pair 变化次数 | 0 | 5 |
| 关系门会放行 | 1 | 3 |
| 点火 | 31 | **76** |

→ 把内部漂移从「只推位置」改成「碰关系记忆」，她的「想」立刻解冻：
新的 pair 出现、点火翻倍、说侧有东西可放行。**这就是 shiromo 的「余响」在 shiro_alice 的对应物。**

## 八、下一步（只观察）

1. 把余响原型做成剂量-反应（p=0.002/0.005/0.01/0.02），看多少漂移合适；
2. 任何「让内部漂移写关系记忆」都是行为改动，等白默拍板；
3. 走/目标规则不再当主干问题。
