# 「意图」的具体改法（2026-11-19 明天照着做）

> 2026-11-18 深夜已经把根因钉死了：**她每一步都走满 618（= 她的半径），
> 但净位移 ≈ 0——因为每走一步都重新选目标，而目标总是对面那个。**
> 所以环不是「走不动」，是**「没有正在去某处」这个状态**。
>
> 这一页是具体怎么改。**没动代码**（改的是 L5 行为，要白默点头）。

## 一、要加什么状态

三个字段（都在 `Stream` 上）：

| 字段 | 类型 | 意思 |
|---|---|---|
| `_heading` | `np.ndarray \| None` | 正在朝哪个方向走（单位向量） |
| `_heading_left` | `int` | 还要朝这个方向走几步 |
| `_heading_goal` | `int \| None` | 目标区域的 uid（用来判断「到了」） |

`__init__` 里初始化（`stream.py` 第 173 行附近，挨着 `_visited_places`）：

```python
self._heading: np.ndarray | None = None
self._heading_left: int = 0
self._heading_goal: int | None = None
```

## 二、`_choose_action` 怎么改（`stream.py:609`）

现在的逻辑：张力 > 中位 → LEAVE，否则 HOLD。

改成**意图优先**：

```python
def _choose_action(self) -> int:
    ...
    # 有意图在走：不重新判张力，继续走
    if self._heading is not None and self._heading_left > 0:
        action = LEAVE
    elif self.force_action is not None:
        action = int(self.force_action)
    else:
        action = self.actions.choose(self._tension_now, list(self._tension_history))
    ...
```

关键：**意图期间张力判据不参与**。张力只决定「要不要立新意图」。

## 三、`_apply_leave` 怎么改（`stream.py:647`）

两条路：

**A. 有意图**：朝 `_heading` 走一个半径，`_heading_left -= 1`；到了或走满就清空。

```python
if self._heading is not None and self._heading_left > 0:
    scale = self._own_scale()
    self._st = DynamicState(x=self._st.x + self._heading * scale, v=self._st.v)
    self._heading_left -= 1
    # 到了？离目标区域质心 < sigma 就清空
    ...
    return
```

**B. 没意图**：照现在的逻辑挑目标；挑到之后**不只是走一步**，而是把方向存下来：

```python
d = self.actions.direction(...)
if d is not None:
    n = float(np.linalg.norm(d))
    self._heading = d / n
    self._heading_left = max(1, int(round(dist_to_target / scale)))  # 几步能到
    self._heading_goal = ...
```

**步数怎么算**：`ceil(dist / s)`。目标 6180 外、半径 618 → 10 步。

## 四、什么时候清空意图

三条，任一：

1. **到了**：离目标区域质心 < sigma；
2. **走满**：`_heading_left == 0`；
3. **撞到别的区域**：走完之后 detector 的 uid 变了，且不是目标 → 说明路走岔了，清空重选。

第 3 条很重要——不然她会一直朝一个已经不存在的目标走。
