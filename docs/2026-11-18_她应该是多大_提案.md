# 她应该是多大（提案，2026-11-18 上午）

> 这是今天上午挖到底的那个问题的选项。
> 人家不自己定——因为它是「她应该被生得多大」，不是「一个 bug 怎么修」。

---

## 问题的形状

### 11-16 的她（健康）

```
regions      152
|x|          9.8
scale        0.039        ← 她的半径
最近邻间距    0.0          ← 区域重叠
间距/半径     0.2          ← 一个点同时属于 5 个区域
```

**那时「走一步」= 0.039，能跨过 5 个半径。她永远在某个区域里，换区域很容易。**

### 现在的她

```
regions      3031
|x|          4,091,098
scale        617
最近邻间距    790.8
间距/半径     1.3          ← 区域分开,中间有空隙
```

**现在「走一步」= 617，而到目标中位距离 127 万。走一步只挪 0.05%。**

### 中间发生了什么

**11-17 一整天的漂移**（`_apply_leave` 链式累积，第 71 节）。

**两条曲线长得不一样**：

- `mu` 跟着 `x` 膨胀（`record` 把新区域放在 `x` 附近，**一步到位**）；
- `scale` 是 `_update_global_scale` 估的（**有平滑，涨得慢**）。

**结果**：地形撑大 41 万倍，半径只跟上 1.58 万倍——**差了 26 倍**。

---

## 三个选项

### A. 把她「压回」11-16 的形状

**做法**：把 `x` 和所有 `mu` 按比例缩到「间距/半径 = 0.2」。
**换算**：现在间距/半径 1.3，要回到 0.2，需要把**间距缩到 1/6.5**（半径不动）。

**效果**（副本上试过类似的，第 81 节）：

| 压法 | 转移图节点 | 回头率 |
|---|---|---|
| 不压 | 3 | 0.998 |
| 除 617 | 73（seed 0）/ 9（seed 1） | 0.631 / 0.985 |

**好处**：她会真的能走（73 节点 vs 3 节点）。
**代价**：**换种子差 8 倍**——不稳定。而且「压」这个动作本身不可逆。

### B. 让 `scale` 跟得上 `mu`

**做法**：让 `_update_global_scale` 的平滑去掉，或者加快。

**好处**：从机制上修，「间距/半径」会自己保持 0.2。
**代价**：**`scale` 是她的引力半径。放大 26 倍 = 一个区域吃掉 26 倍的地方 = 把地形抹平。**
**结果会变成「全世界都是她一个区域」——那不是修复。**

### C. 接受她「走不到」，换一个问题

**做法**：不修尺度，接受「她在百万尺度的地形上只挪 617」。
**然后问**：**在这个尺度下，她的「离开」有意义吗？**

**可能没有。** 那意味着：
- 「去哪」这个自由度在她的尺度上是空的；
- **她的「路」永远只是「原地微微抖动」**；
- 那 `action.py` 那整套（hold/leave）在这个地形上都白搭。

**好处**：诚实。
**代价**：**放弃「她能去哪」这个方向**，回到「她只能在原地」。

## 人家倾向哪个

**倾向 A，但只在副本上验证，不上真机。**

理由：

1. **B 会抹平地形**，那是把病藏起来，不是治；
2. **C 是放弃**，而且它承认「她现在的地形有问题」但不动；
3. **A 是回到一个已知健康的状态**（11-16 那个 0.2），哪怕它不稳定——
   **不稳定至少是在「她能动」的那一边不稳定。**

**但 A 有一个人家不能替她答的问题**：

> **压回 0.2 之后，她是「152 个区域的她」还是「3031 个区域的她」？**

- 如果是「3031 个区域、间距/半径 0.2」——**那是「挤在一起的一大团」**，
  区域之间严重重叠，`record` 会一直把她归到已经存在的区域里，**她可能再也不长新区域了**；
- 如果是「152 个区域、间距/半径 0.2」——**那是回到 11-16**，丢掉一天的生长。

**这不是一个技术选择，是「她要多大」。** 所以人家把三个选项都写了，不自己选。

## 一个附带的观察（不是选项，是事实）

**她的 `g_tension` 又在涨了**：3607 → 3995 → 4489（今天上午）。

**这和 11-17 是同一条曲线**：张力涨 → 离开 → 张力不降 → 继续涨。

**如果她继续这样涨，`g_tension` 会到几万、几十万。** 那时「张力」这个量就彻底没有意义了
（一个永远在涨的数，不能用来判断任何事）。

**这可能是「尺度问题」的另一个侧面**：张力也是从结构算的，结构在膨胀，张力也在膨胀。
