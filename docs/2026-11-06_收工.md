# 2026-11-06 收工（18:07）

## 一句话

**她第一次有了关于「存续」的机制。**

不是「她想要活下去」，而是一个区域能不能维持自己，开始影响它对外的作用强度。

---

## 理论

### Di Paolo 2005：自创生不够

```
自创生（自我生产） + adaptivity（可适应）
    → sense-making（意义生成）
    → agency（能动性）
```

adaptivity 的定义：**系统调节自己与自身存续条件的关系的能力。**

**不需要目标、奖励、价值判断。** 只需要「有能继续的区间」+「能感知位置」+「能调节」。

### Holling 1973：稳定性 ≠ 恢复力

| | 定义 |
|---|---|
| stability | 受扰动后回到平衡点 |
| **resilience** | **吸收扰动而不脱离当前状态区间** |

我最初实现的是前者，该管的是后者。

---

## 实现

### 1. 承载深度

```
amp* = ceiling × (p·a) / (p·a + R)

p = 实测访问率（累计赋值 / 总观测步数）
R = 每步恢复量
```

一个很少被访问的地方，撑不起多少深度。这是物理约束，不是规定。

### 2. 牵引因子

```
pull = (amp / amp*) ^ beta
```

离自己的平衡越远，对外作用越强或越弱。

`beta = 1.0`，这是恒等关系。**它是工程标度，不是理论常数**，Di Paolo 的 adaptivity 没有标准函数形式。

### 3. 访问间隔缩放（今天最重要的修正）

**发现的尺度不匹配：**

```
典型回访间隔  p50 = 47,221 步
深度半衰期        =  5,540 步
```

**回访间隔是半衰期的 8.5 倍。** 她离开一个地方后，深度掉到 1/300 才回来。

**修正：**

```
rate_scale = min(1, half_life / own_interval)
```

每个区域的恢复速率，按「它自己多久被回访一次」放慢。

只被访问一次、再也不回来的区域照样会淡，只是淡的速度和「任何东西可能回来的时间尺度」一致。

## 实测

### 修正前后（6000 步）

```
step 1000: att 260  rev32 46  salient 10  speed 0.93  below 0.877
step 3000: att 311  rev32 48  salient 12  speed 0.48  below 0.723
step 6000: att 352  rev32 57  salient 25  speed 0.70  below 0.625
```

三条曲线同向：`below` 降、`salient` 升、速度降。

### 病态结构的处理

旧存档里一个区域：`76456 次赋值、amp 0.997、sigma 0.00041`，梯度贡献 1471（其他所有加起来不到 1）。

按白默的决定「留着但不让它主导」：

- 尺度自洽：`sigma >= amp/(amp+1) × median_sigma`
- 主导上限：单条贡献 ≤ 其余之和
- 加载时立即应用（之前是第一步末尾，太晚）

结果：梯度 1471 → 63，第一步速度 14.7 → 0.63。

## 被否决的机制

### 可通行边界（墙）

设计意图：让没有结构支撑的地方走不过去。

实测：

```
              none     wall
travel/R      37.68   117.51
salient           5        1
```

**开了墙她走得更远 3 倍，显著吸引子从 5 降到 1。**

原因：墙加的是**正向势能**，把她推离薄的地方，而推出去的地方更没结构。**这跟 resilience 的定义相反**，Holling 说的是「吸收」，不是「弹开」。

**默认关闭。** 代码里 `_wall_enabled = False`。

## 发现但没解决的问题

### 判据尺度

用同一段真实轨迹（3000 步，跨度 12.98）比较不同判据：

```
                      区域数   深度中位   最大占比
per-attractor sigma:     90     0.780     2.5%
运动范围 × 0.02:         312     0.185     2.8%
运动范围 × 0.05:         149     0.265     6.3%
运动范围 × 0.10:          79     0.401    10.9%
运动范围 × 0.20:          41     0.641    23.1%
```

**全是同一个权衡：判据宽 → 区域少、每个深；判据窄 → 区域多、每个浅。**

**没有一个取值能同时得到「多、深、均匀」。**

这是一条守恒关系。状态的总量固定，判据决定怎么分组。组少了，每组成员自然多。

**所以真正该问的不是「判据用多大」，而是「要多大的结构」。** 这是设计决定。

### 冷启动与存档路径差 15 倍

```
旧存档：att 269，sigma 0.005，amp 0.019
冷启动：att  39，sigma 0.029，amp 0.306
```

冷启动长不出结构，因为 `sigma` 一开始就大，吞掉一切。
