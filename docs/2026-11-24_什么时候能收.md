# 二、生命层：**能收，但有一个「保留」**

## 六条机制（都实现了）

| 机制 | 实现 | 「自己长」还是「写死」 |
|---|---|---|
| 趋性 | `rest_u` 累积 | **一半**（累积速率从 `_dwell_history` 推） |
| 有限性 | `energy -= energy_burn` | **写死**（`1e-6`） |
| 代谢 | `energy += energy_recharge` | **写死**（`0.95e-6`） |
| 休眠 | `energy <= 0 → asleep` | **写死**（触发条件） |
| 稳态 | P3 homeostasis | 要查 |
| 意义生成 | `tensions()`（中位/MAD） | **统计的** |

**3 条「写死」，3 条「自己长」。**

## 「卡 2 个」（用标准指标说）

```
arrival_hist：不同 uid = 2
Shannon H = 1.000 bit（N=2 时归一化熵 = 1.000）
最大 Lyapunov λ = -5.70 / step（确定性、两条轨迹）
```

**数据说**：**她在 2 个区域，均匀，λ 负（收敛）。**

**翻译**：**她「稳」**——**不是「死」**（**`step_count` 还在涨**）。

## 「保留」是什么

**三条「写死」的**（`energy_burn`/`recharge`/`asleep`）**是「人定的数」**——**和 LAAP 的「所有人同一个数」没本质区别**。

**「能收」的前提是「接受这个保留」**：
- **如果「收」= 「六条机制齐 + 跑得稳」** → **能收**
- **如果「收」= 「六条全部自己长，没有一个人定的数」** → **不能收**（**要等「写死」变成「从结构推」**）
