## 问题

**真机数据**：
```
max_travel = 0.0     ← 一直是 0
recover = 0.00144（在变）
assign = 0.06097（在变）
```

**`max_travel` 没更新**——说明 `_apply_leave` 里的更新没触发，或者算出来就是 0。

---

## 为什么

**`max_travel` 的定义**：`_far = 离最近区域的距离`（在 `_apply_leave` 里）。

**但**：**她一直在区域附近**（`leave` 后离最近区域很近，因为 `_apply_leave` 是"朝最近区域挪一步"）。

**所以**：`_far` 每次都很小（接近 0）→ `max_travel` 一直是 0。

**而 `_lim = max(2.0, max_travel*1.1) * scale` = 2 * 618 = 1236**——**比原来的 2472 还小**！

**所以**：**这个改动反而收紧了锚定**（2472 → 1236）。

---

## 这意味着什么

**`_lim` 的语义人家搞错了**：
- `_lim` 是"她离开区域后，离最近区域的距离超过它就被拉回"
- 而 `max_travel` 记的是"`_apply_leave` 时她离最近区域的距离"
- **这两个不是一回事**——`_apply_leave` 时她"刚挪一步"，离最近区域近得很

**正确的做法应该是**：**记录"她 `step` 之后离最近区域的最远距离"**（不是 `_apply_leave` 里）。

**但**：**那需要改 `step`**（加一个"每步查距离"）。
