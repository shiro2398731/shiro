# 清理假分层 · 阶段 6：wall 死开关（2026-11-28 00:35）

## 删了什么

- `Stream._wall_enabled = False`（恒 False，只有 stream 自己引用）；
- `if self._wall_enabled: set_wall(viability.wall(ss)) else: set_wall(None)` 的**整个 if**，
  换成每步显式的 `set_wall(None)`。

## 行为

**完全不变**：原来 flag 恒 False，等价于每步都走 else 分支（`set_wall(None)`）。
现在只是把「永不生效的上半支」删掉，保留同一个活行为。

## 为什么删

- wall（traversability edge）实测开启后会推远状态（6→150 σ），与「吸收扰动」相反，
  属于已否决的机制；
- 留一个恒 False 的开关，只会让后人以为它「随时能开」。

如果以后真要做边界，应该按新设计重写，而不是复活这个 flag。
