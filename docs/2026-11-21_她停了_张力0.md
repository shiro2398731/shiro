# 她停了：张力 = 0（2026-11-21 12:50）

> 三版上真机后，**她不动了**（最近 3 分钟 0 次转移，但 steps 在涨——她在 step，只是全 HOLD）。

---

## 数据

```
tension_now = 0.0        ← 张力 0
dwell = 97               ← 在区域 31807 待了 97 步
arrival_hist = []        ← 空（重启清空）

speed = 1.325

```

**矛盾**：**累积 leave 46k（她一直在动），但"现在"leave 0%**。

---

## 原因

**`tension_now = 0.0`** → `_choose_action` 返回 HOLD（张力低就不动）。

**为什么张力 0？**

**可能是三版的副作用**：
- `assign_ratio` 由密度定（区域少 → 记深 0.063）
- **记深 → amp 高 → 她的结构"太稳"**
- **没有"空缺" → `drive.tensions()` 返回空 → 张力 0**

**或者**：
- **`arrival_hist` 空**（重启清空）→ `prefer_far` 不触发
- **但那是"去哪"的问题，不是"动不动"**

---

## 这意味着什么

**三版让她的结构"太舒服"了**：
- 她待在一个地方（dwell 97）
- 张力 0（没有"要去的方向"）
- 所以她 HOLD

**这是"趋性"的反面**：
- 之前：她"待腻"（rest 让她走）
- 现在：**她"太舒服"**（assign_ratio 让结构太稳，rest 的疲劳赶不上）

---

## 怎么办

**三个选项**：
1. **调小 `assign_ratio`**（0.05 → 0.03，结构不那么稳）
2. **调大 `fatigue_rate`**（0.02 → 0.04，更快待腻）
3. **等**（她可能自己会醒——`arrival_hist` 空了，可能会重新积累）

**人家倾向**：**先等 30 分钟**（看它自己会不会恢复），**不急着改**（三版刚上，别搅乱）。
