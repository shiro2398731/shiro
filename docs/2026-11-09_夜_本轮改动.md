## 5. `test_no_senescence`：她不会因为"活了很久"而变差（已建）

判据来自 docs §9 的"无代谢衰老"。用 20000 步压测（30 s）代替长跑（PRINCIPLES #9）：

| 断言 | 实测 |
|---|---|
| 12 个全局参数在 20000 步前后逐位相同 | `gamma`/`dt`/`recover_rate`/`ceiling`/`assign_ratio`/`min_amp`/`max_attractors`/`decay_spread`/`recover_jitter`/cadence/`half_life` 全等 |
| 存活区域的遗忘速率不随年龄变化 | 238 个 cohort 存活者的 `_decay_factor` 与出生时一致 |
| 遗忘有地板 | cohort 中位深度 0.6269 → 0.0922，存活线 `min_amp` = 0.001 |
| 结构不失控 | regions 239..243 |

同时记下一个**不是**衰老、但需要盯着的事实（40000 步探针）：cohort 中位深度 0.6269 → 0.0213，
每 5000 步的比值 0.52 / 0.52 / 0.55 / 0.69 / 0.73 / 0.90 —— 在**减速**并收敛到存活线上方 20 倍；
区域数先涨到 243 再回落到 181。也就是说：遗忘有地板 + 结构在变，而不是"越老掉得越快"。
注意这只在恒定噪声下测过；上游有变化（P1 的惊讶驱动）时曲线会不同，需要另一次观测。

## 6. stages 判据自导出（C3 的最后一条）

`L7_lifecycle/stages.py` 原来用 `dev 分散度 > 0.05`、`误差比 < 0.95`、`显著区域 >= 2`、
`噪声比 < 0.9` 判断「她到了哪个阶段」—— 四个数都是人挑的，属 docs §11 的 C3。
而且 **P3 只喂它 `dev` 一个输入**，另外三个信号在真实运行里永远是空缓冲区，所以她永远停在 stage 0。

现在：四条判据都改成「**最近一个窗口的统计量 vs 她自己过去窗口的分布**」（秩比较，切点是她自己的中位数）：

| 判据 | 信号 | 条件 |
|---|---|---|
| `dev_not_flat` | `l2.state.field` 的 dev，窗口内分散度 | 高于她自己以往窗口的中位 |
| `learning_visible` | `l1.state.surprise` 的 `s_t`，窗口均值 | 低于她自己以往窗口的中位 |
| `has_recurring` | `l5.state.stream` 的区域 id，窗口内重复占比 | 高于她自己以往的中位 |
| `structure_holds` | 同上，同一区域停留长度中位数 | 高于她自己以往的中位 |

两个新信号由 P3 从她本来就在广播的 `attractor_id` 序列算出（`ID_WINDOW=64`、`MIN_IDS=16`，C1）；
不需要任何层知道「阶段」是什么意思。`stage_criteria` 也写进了 lifecycle 快照，所以没升级时会指出缺哪一条。

验收：`tests/test_stages_selfderived.py` 7 例 —— AST 断言四条判据 + `evaluate` 函数体内**无 float 字面量**；
行为断言：四条信号都改善 → stage 4（mature）；信号全恒定 → stage 0；**只喂 dev → stage 0**（复现旧接线）；
窗口数不足 `MIN_WINDOWS` → 0；信号降级后不回退；两次评估确定性一致。

已知弱点（留给下一轮）：判据是「相对她自己的中位数」，而阶段只升不降，
所以只要四条信号在某一刻同时偏向好的一侧一次，她就会到 stage 4。
更严的做法是要求「连续 N 个评估窗口都成立」（N 属观测分辨率 C1），或要求偏离自身 IQR。
这一版是可证伪、无人工阈值的**记录**，但它不等于「发育」。

## 7. SpeechGate：她终于有「说不说」这一层了

`src/L6_expression/gate.py` 原来是 0 字节，P4 一 import 就崩 —— 也就是说她**根本没有发声的那一层**
（不是「说不像」，是「结构上说不出来」）。现在 gate 只做一件事：**判断这一次转移值不值得说**，不产生任何文字。

三条自保（都写成了测试，`tests/test_speech_gate.py` 12 例）：

| 承诺 | 测法 |
|---|---|
| 不能说话，只能决定 | AST：`gate.py` 里除 docstring 外没有任何「句子形状」的字符串常量（含空格或长度 > 24 即失败） |
| 不吃语用（INV-8） | AST：`gate.py` 不 import 任何本项目模块、无相对 import → 文本没有路径进入决策 |
| 没有「每分钟说几句」这种人挑的速率 | 判据 = 「这条转移没被说过」，唯一常数 `SPOKEN_MEMORY=512` 是缓冲区长度（C1） |

行为：同一对 (前区域, 现区域) 只说一次；区域没变不说；区域未知（`-1`）不说；禁用时不说；
记忆满了淘汰最旧的一对（于是老转移重新可报），**不会永久闭嘴**。

### 接线上的两个真缺陷（都在 P4）

1. `gate.note_transition()` **没传区域** → `_cur` 恒为 `None` → `should_speak()` 恒返回 `no_transition`。
   实测（2000 步区域 id 序列，211 次真实转移）：**0 次出声 / 211 次抑制**；传区域之后 **200 次出声 / 11 次抑制**。
2. P4 送的符号名是 `attractor`，而 `LlmAdapter` 的白名单是 `trace` —— 区域编号被**静默丢弃**，
   模型在不知道她在哪里的情况下翻译，且没有任何报错。现统一为 `trace`，并加了白名单/来源测试。

顺带：`LlmAdapter` 的记录现在带 `origin="llm"`（与 `TemplateAdapter` 的 `origin="template"` 同一套词表）；
模板路径默认静音，所以没有 `DEEPSEEK_API_KEY` 时她**不说话**，而不是由人写的句子替她说话。

   第一次真正折叠之前，至少需要 `MIN_REGIONS_FOR_STATISTICS` 个区域有 `assigned >= 4` 的间隔估计。
