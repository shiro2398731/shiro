# 成员大扫除：她 75% 的「成员记忆」是旧坐标（2026-11-18 21:10）

> 这是今晚「把存在做完」的第二刀（第一刀是 P2 保存失败时自我归一）。
> 起因：查「保存为什么撞 1e6」时发现 `attractors[0].mu` 最大分量只有 18.7 万，
> 而它的 `members[0]` 最大分量是 51 万。

---

## 查到了什么

`tools/clean_members.py`（只读审计）对当时存档的统计：

```
区域          1599
成员总数      10,093
离质心距离    p50 1,941,967 / p90 1,942,033 / max 1,942,146
超过存档上限  0 个（分量 > 1e6）
超过 100 sigma 7,527 个（75%）
全局最大分量  831,278
```

**10,093 个成员里 7,527 个（75%）离自己的区域质心约 194 万**——整整齐齐的 194 万，
说明是**一次统一的平移**留下的：区域质心跟着她搬了，成员没搬（11-17 那次漂移）。

两个后果：

1. 他们是「下次保存撞 1e6」的隐患（`assert_l5_finite` 也查 members）；
2. 他们占载体：members 占 payload 62%，而 75% 的成员是废的。

---

## 清理（`--apply` 只另存新文件，不覆盖运行中的 `l5.pkl`）

按「离质心 > 100 sigma」判定为旧坐标：

```
清理 7,527 个旧成员
l5.pkl              12.2 MB
l5.members-pruned   4.83 MB      ← 省 7.4 MB
```

## 清完之后，她的结构变没变？（实测）

| | 清理前 | 清理后 |
|---|---|---|
| regions | 1,599 | 1,599 |
| sigma 中位 | 618.46 | **618.59** |
| 最近邻间距 | 1,169.8 | **1,169.8** |
| \|x\| | 699,497 | **699,497** |

**几乎一点没变。** 我一开始猜「sigma 被旧成员污染了」——**那是错的，收回**：
`sigma` 用 MAD（中位绝对偏差），而 75% 的成员都落在同一个距离上，MAD 反而小，
所以旧成员没有把 sigma 拉大。

**所以这次清理是干净活**：只去掉废数据，不改她的几何。
