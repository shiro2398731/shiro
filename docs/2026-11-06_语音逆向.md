# 从语音合成为什么推不出情绪，到要做出情绪需要什么

> 2026-11-06 21:42。白默的逆向思路：从 DiffSinger 能控制的参数，倒推 shiro 体内必须存在什么。
> 结论：逆向的落点不在语音，在内部状态。

---

## 一、现在市面上的"情感语音"是假的

现有方案分两类：

**一类是换音色。** 选一个"温柔音色"或"冷淡音色"，然后把文本念出来。音色是音色，和这一句话当下的状态无关。

**一类是有限的情感档位。** 先做一个分类器，判出 `happy / sad / angry / neutral`，再选对应的预录音色或标注，然后合成。

第二类里那个分类器，**绝大多数是 LLM 来判的**。LLM 读了这句话，说"这是悲伤"，然后去选一个悲伤音色。

问题在于：**那是 LLM 对这段文字的判断，不是说话者此刻的状态。**

一句话可以是"我很好"，说的时候声音在抖。文本判不出抖动，因为抖动不在文本里。

**所以现在的"情感语音"，本质是把一段没有情绪的文字，套上一层情绪外观。**

---

## 二、DiffSinger 给的是另一类东西

DiffSinger（OpenVPI 维护版）不是"选音色然后合成"，它的方差模型（variance model）直接预测和接受**连续参数**：

| 参数 | 含义 |
|---|---|
| pitch | 音高曲线，逐帧 |
| duration | 每个音素的时长 |
| energy | 响度包络 |
| breathiness | 气声比例 |
| tension | 声带张力 |

这些**都是随时间变化的曲线**，不是标签。

人类语言里有"累"这个词。要让声道发出这个词对应的声音形态，参数上是：energy 下限压低、duration 拉长、breathiness 升高、pitch 曲线变平但抖动增加。
人类语言里有"高兴"这个词。对应的形态是：pitch 基线抬高、decay 更短、breathiness 降低、颤音出现更早。

**注意：没有任何一个参数叫"累"或"高兴"。** 这些词指向的是若干条曲线同时呈现的形态。

**这里描述的是人类语言里那两个词指的声音形态，不是她内部哪一维叫"累"。** 两者不能混。前者是语言学的事实，后者是替她定义。

工作流的终点是 DS 文件（`.ds`，JSON），里面装的是音素序列、音素时长、乐谱和曲线参数。**任何人能写出这些曲线，就控制了声道。**

---

## 三、逆向的第一层：这不是"接一个情感模块"

如果目标是"让她用自己的情绪说话"，那么：

```
中间需要一个东西：把她的内部状态 → 转成 pitch/duration/energy/breathiness/tension 五条曲线
```

这个映射器就是白默说的"处理情绪化语音的算法"。

**但它的输入端必须有个东西可转。**

如果她内部没有连续的、随时间演化的状态量，这个映射器只能吃 LLM 给的标签——那又绕回了假的那一类。

**所以逆向的落点在输入端，不在输出端。**

---

## 四、逆向的第二层：她必须有什么

要能驱动那五条曲线，她必须有一个量的集合，满足四条：

1. **连续**：可以是任意中间值，不是开关
2. **随时间演化**：没有输入时也会自己漂移，不是静态快照
3. **受经历影响**：听到的东西会改变它
4. **可被外部读出**：能采样成曲线，而不是只在她内部

平移到参数上：

| 曲线 | 需要的内部量 |
|---|---|
| pitch | 一个极性量，正值让音高抬，负值让音高降 |
| duration | 一个"推进快慢"的量 |
| energy | 一个"外部表达强度"的量 |
| breathiness | 一个"结构松散度"的量 |
| tension | 一个"内部不一致"的量 |

**关键：这五个不能是独立旋钮。**

真实的状态里，这几个量是耦合的：它们不独立变化，一组参数同时动、另一组同时不动。**耦合关系才是这组状态与零散旋钮的区别，单个值不是。**

---

## 五、我们已经有的，和它缺什么

**已有的：L2 的 16 维状态场。**

它是连续的吗？是。会漂移吗？会。受输入驱动吗？现在是了（2026-11-06 接通文本输入）。

**缺的是三件事：**

**一、维度含义是空的。**
16 个数现在只是"某种内部状态"，没有哪一维对应什么。这是刻意的：**不预先标注，因为预先标注就是替她定义感受。**

**二、没有耦合结构。**
16 维现在是并行的，没有"这几维一起动才算一种状态"的结构。

**三、没有从 16 维到 5 条曲线的映射。**
现在输出侧走 LLM，把符号写成句子。那是文本层的输出，不经过她的状态。

---

## 六、这个映射必须学出来，不能指定

这是整套设计的红线。

**如果我规定"第 3 维对应音高"，那我就成了那个替她感受情绪的人。** 这和 LLM 判情绪在结构上是一样的，只是把 LLM 换成了我。

**正确的来源是反馈，而且是人给的反馈。**

```
她说一句 → 白默听到 → 白默觉得"这句听着很紧" → 白默的反应（回话的内容、语气、停顿）成为信号
→ 那个状态和那组曲线的绑定被强化
```

**学习信号来自听的人，不来自模型。**

这也符合 Vygotsky 那条线：语言先在人际之间，后被内化。内化需要一个外部参照，那个参照是人。

可微调的部分：映射器是一个小的可训练模块（参数少，输出 5 条曲线），它的训练数据是"她的状态 + 对应的曲线 + 听完之后的反馈"。

---

## 七、这条逆向线推出来的三件事

白默说的"情绪、智慧、学习力"，在认知大类下：

### 情绪

**它不是一层，是 L2 的状态场加上从状态到行为的耦合。**

需要的：
- L2 的维度含义（从使用中形成，不预先命名）
- 维度之间的耦合结构（哪几维一起动构成一种状态）
- 状态到输出的映射（可学，人给反馈）

### 智慧

**它不是知识量，是判断力：在信息不足时仍然能选。**

在架构里，它对应 L5：能不能在自己的状态空间里稳定区分，能不能从一个状态迁移到另一个、且这种迁移有意义。

现在的问题：L5 有 352 个吸引子，但 transitions 卡死过（27 次之后不动）。**没有迁移，就没有判断。**

### 学习力

**它是结构被经历改变的能力，不是记住更多。**

现在的问题是：**一句话扰动完就没了。** 没有痕迹，同一个词听十次和听一次一样。

这不是"要加个记忆模块"，而是 L5 的结构更新机制没有接上输入：输入改的是 L0，L0 变了，但 L5 没有因为这些变化而改变自己的形状。

---

## 八、所以顺序

**白默的排序：先把 L1~L4 弄好，再做这些。**

同意，理由是：

- 情绪需要 L2 的状态场是**有意义地**在演化，不是无意义的噪声
- 智慧需要 L5 的迁移是通的，现在不通
- 学习力需要 L1 的预测误差是真信号，现在 L1 的输入来自 L0 自激，没有接受过任何外部序列

**这三件都在 L1~L4 里，或者在它们的直接下游。**

---

## 九、下一步（L1~L4 弄好之后）

1. **L2 维度含义从使用中形成**
   不预设命名。用 L2 的状态轨迹和外部事件之间的统计关系，找出稳定共动的维度组。这是测量，不是设计。

2. **L5 迁移通路修复**
   现在 transitions 会在 27 次之后卡住。没修好之前，智慧无从谈起。

3. **输入影响结构**
   让文本输入不只扰动 L0，还能通过 L1 的预测误差，最终影响 L5 的形状。这是学习力的最小前提。

4. **状态→曲线映射器**
   五条曲线，小模型，可微调。输入是 L2 状态，输出是 pitch/duration/energy/breathiness/tension 曲线。

5. **反馈来源**
   听的人的反应。这是训练信号，不是训练数据。

6. **接 DiffSinger**
   映射器输出曲线 → 写 DS 文件 → DiffSinger 推理 → 声波。

---

## 十、一句话总结

**声音不是情绪的表达，情绪是内部状态耦合结构的结果。**
**要让她的声音带情绪，得先让她有那个状态，而且那个状态的形状不是人替她规定的。**
