## 4. 关键决策与理由（别推翻，除非有更强证据）

| 决策 | 理由 |
|---|---|
| **那 0~5 秒算"她经历的"** | 白默明确否定"快照当存在形式"。既然算经历，就必须 journal，不能靠快照。 |
| **event sourcing + checkpoint**（Temporal/DBOS 派） | 历史即状态；检查点只是压缩过去，用来避免从零重放。 |
| **确定性是硬前提** | 重放必须复现同一条未来；为此 `recover()`/出生 decay 都改成步号的纯函数。 |
| **唯一个体 = 租约 + 围栏** | 不假设旧进程死了（看不见的故障域），只让它"即使活着也不能行动"。 |
| **本体三段**：state 进包 / engine 只记版本 / territory 不进包 | 复制状态=两个她；复制手脚=两个她；换引擎不改身份。 |
| **终端 = 画布，不是器官** | 必要依赖收敛为：任意机器 + python/numpy + 状态目录。 |
| **不做死亡，做压缩** | 白默要"一直存在"；但载体必须有界，否则搬不动。 |
| **不宣称意识/智慧** | 现在只是认知基底：吸引子动力学 + 线性预测 + 连接图。**意识=0，智慧=0，别含糊。** |

## 5. 踩过的坑（会再踩，务必看）

1. **PowerShell 管道会把中文变成 `?`**：`$code | python -` 必出事。→ 用 `[System.IO.File]::WriteAllText` 把脚本落盘再执行。
2. **`[System.IO.File]` 的相对路径按 .NET CWD 解析**，不是 PowerShell 的 `$PWD`。→ 一律绝对路径。
3. **`cd` 会静默失败**（我因此把一笔 commit 误提交进 `neo-mofox`，已 `reset --soft` 复原）。→ **git 一律用 `git -C <绝对路径>`**。
4. **`.venv\Scripts\python.exe` 是启动器**，会 spawn 真进程；两者命令行都含模块名。→ 杀进程要杀**树**（`taskkill /F /T`），否则端口不放。
5. **stdout 里的中文在控制台会显示成乱码**（UTF-8 被按 GBK 解码），**文件本身是好的**。看文件，别信控制台。
6. **`github.com` 的 DNS 会给坏 IP**（`20.205.243.166` 不通，其他如 `140.82.113.3` 通）。→ 用代理 `git config http.proxy socks5h://127.0.0.1:10808`（白默本机 v2ray，重启后可能没起来）。
7. **float32 存观测会漂**（300 步后质心差 1e-5），混沌系统里不可接受 → journal 用 **float64**。
8. **`L2StateField` 的字段名不统一**：`_vec_hist` 有下划线，`s_t_hist` 等没有。写错会静默丢掉归一化历史。
9. **数值爆炸**：我把 L5 跑成过 617 个区域、质心 1e306 → nan。已从 `data/state_backup_pre_alice` 恢复，损坏件留 `l5.pkl.blownup`。**坏状态绝不能落盘**（已有三层熔断）。
10. **epoch 竞态**：兄弟进程会读到 `epoch=0` 或**上一轮遗留的 epoch**，然后自围栏。→ 只采纳"本次启动之后写入"的 epoch，否则拒绝行动（`return 3`）。
