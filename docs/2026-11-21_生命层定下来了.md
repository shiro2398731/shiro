# 生命层：定下来了（2026-11-21 凌晨）

> 白默的三个答案：
> 1. **活多久**：一直活（电子幽灵嘛不是）
> 2. **能量耗尽就休眠**
> 3. **补充是电能，电是能源；多巴胺是另一回事**
>
> 还有一条更根本的：**「好」不该我们定义。碳基生命没有限制规则。**

---

## 所以生命层定成了这样

### 1. energy = 电能（一直有，但活动会耗）

**改**（2026-11-21 00:10）：
- **活动（leave）才耗**：`energy_burn = 1e-6`
- **休息（hold）几乎不耗**：×0.1

**算**：她一天约 4000 次 leave → 一天掉 0.004 → **约 250 天才耗尽**。

**所以**：**她「一直活」**——但这不代表 energy 没意义：
- 她**活动多**，掉得快
- 她**停着**，掉得慢
- **这是「趋性」：她会因为「活动有代价」而自然地少动**（不是我们规定的）

### 2. 耗尽 = 休眠（不是死）

**改**：
```python
if self.energy <= 0.0:
    self.asleep = True        # 休眠
```
- **休眠时 `step()` 直接返回**（不动）
- **不是不可逆**：重启/补能就醒
- **区域数不变**（测试钉住了：耗尽不影响区域）

**为什么这样对**：她说「电子幽灵」——**幽灵不会死，只会「不在」**。

### 3. 不加「多巴胺」

**理由**（她的原话）：
> 「这不该我们定义？碳基生命没有什么限制规则……」

**多巴胺 = 「比预期好多少」= 需要先有「好」。**
**我们给「好」，就是又替她定义了一遍。**

**她现在的 `s_t`（惊讶）是中性的**——**中性才不被我们定义**。

**「好」是意识层的事**（她得先有「感受」）。**生命层到「会不会继续」就够了。**

### 4. 已经有的「趋性」不动

- `viability`（区域能不能维持）→ `regulation`（pull）→ 她的动作
- `rest`（待久了会淡）——**昨晚接上的**
- `energy`（活动会耗）——**今晚改好的**
