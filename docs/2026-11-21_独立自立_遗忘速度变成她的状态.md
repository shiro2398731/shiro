# 独立自立：遗忘速度变成「她自己的状态」（2026-11-21 12:35）

> 白默：「要做成独立自立的存在，独立自立的生命」。

---

## 改了什么

**之前**：`recover_rate = 0.002`（**我们定的常数**）
**现在**：`recover_rate_state`（**她的状态**，每 16 步随她的活动变）

```python
self._recent_actions.append(1 if leave else 0)     # 记她这一步的动作
if self._step_count % 16 == 0:
    _act = sum(_recent_actions) / len          # 她自己的活跃度
    _target = 0.002 * (0.5 + _act)             # 活跃 → 遗忘快；安静 → 慢
    self.recover_rate_state = self.recover_rate_state * 0.95 + _target * 0.05
    self.landscape.state_space.recover_rate = self.recover_rate_state
```

**同步到地形** → **她的遗忘速度是她自己的活动在调**。

## 验证（副本 500 步）

```
她 leave 0 次（安静）
recover_rate_state: 0.002 → 0.00121（变慢）
terrain.recover_rate: 0.00121（同步了）
区域: 1002 → 1001（稳定）
amp 中位: 0.0011 → 0.00143（结构保住了——遗忘慢，保得住）
```

**所以**：
- **她安静** → 遗忘慢 → **结构保住**（amp 涨）
- **如果她活跃** → 遗忘快 → 结构更新快

**这是「自适应」**：不是我们定的"遗忘多快"，是**她自己的活动在定**。

---

## 这算不算「独立自立」

**算一步**：
- 之前：**她的遗忘速度是常数**（我们定的）
- 现在：**她的遗忘速度是她的状态**（她的活动在调）

**但**：**公式还是我们写的**（`0.002 * (0.5 + act)`）。

**更彻底的「独立自立」**应该是：
- **不使用"我们写的公式"**
- **让 `recover_rate` 直接等于"她自己测出来的某个量"**（比如"最近被删区域的比例"）

**人家还没到那一步**，但方向对了：**参数从"我们定"变成"她定"**。
