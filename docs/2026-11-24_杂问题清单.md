# 杂问题 1：她为什么不睡（睡眠其实被抵消了）

## 代码

```python
if not self.asleep:
    _burn = self.energy_burn if self._action == "leave" else self.energy_burn * 0.1
    self.energy = min(1.0, max(0.0, self.energy - _burn + self.energy_recharge))
    if self.energy <= 0.0:
        self.asleep = True
```

## 实际数值

```
energy = 1.000000
energy_burn = 1e-6
energy_recharge = 0.95e-6
asleep = False
```

## 每步净变化

| 动作 | `_burn` | `+recharge` | 净 |
|---|---|---|---|
| **LEAVE** | **1e-6** | **0.95e-6** | **-5e-8**（掉） |
| **HOLD** | **1e-7**（burn × 0.1） | **0.95e-6** | **+8.5e-7**（涨） |

## 结论

**她 HOLD 占多数**（`arrival_hist` 只有 2 个区域，大多在原地）——**净涨**——**能量一直 1.0**——**`asleep` 永远不触发**。

**所以「休眠」机制「在，但不会触发」**——**「有限性」被她自己的「HOLD 折扣」抵消了**。

**BU G**：**这是「设计」**（**`burn*0.1` 是为了「不动就不耗」**）——**但「recharge 0.95e-6 > burn*0.1 = 1e-7」**——**不动就「净涨」**——**她「不饿」**。

**白默说「睡眠优先级不高」**——**人家同意**——**但这是「机制在、不触发」**——**记录**。
