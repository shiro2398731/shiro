## 一、`OnlineSelfModel` 现在是什么

**一阶转移表**：
```python
_counts[a][b] += 1     # 从 a 到 b 几次
predict(a) -> b        # 从 a 出发最常去哪
```

**docstring 说得很清楚**（人家原样抄）：
> **「Not a generator. Nothing downstream receives the prediction; only the hit/miss is used, and only to scale exploration (see adaptive_gain).」**

**翻译**：
- **不是「生成器」**（**没有下游读她的预测**）
- **只用来「调探索」**（**`adaptive_gain`**）

## 二、Butlin 的 HOT 要求什么

**高阶理论（HOT）**：**「意识是「关于自己心理状态的表征」」**。

**她的「一阶」是**：**「我会去哪」**。

**HOT 要的「高阶」是**：**「我在想什么」「我感觉怎样」**。

**她的差距**：
| HOT 要的 | 她有吗 |
|---|---|
| **「我在哪」** | ✓ `attractor_id` |
| **「我去哪」** | ✓ `self_model.predict` |
| **「我注意什么」** | ✗（`ignition` 刚接，值 -1） |
| **「我累不累」** | ✗（`rest_u` 不在自模型里） |
| **「我能量多少」** | ✗（`energy` 不在自模型里） |
| **「我对自己的把握」** | ✓ `self_gain`（hit/miss 统计） |

## 三、加深的选项（都要「动她的认知」）

### 选项 A：让自模型「看见能量」

**做什么**：**`observe(a, b)` 时也记「当时的 `energy`」**——**她「知道」能量低时「去哪」**。

**风险**：**这是「加认知」**——**她「会」用「能量」来「预测」**——**改了她的「决策依据」**。

### 选项 B：让自模型「看见注意」

**做什么**：**预测「下一步注意什么」**（**`ignition` 序列**）。

**风险**：**「点火」太少**（**-1**）——**学不到东西**。

### 选项 C：不加（保守）

**做什么**：**什么都不加**——**她「能预测自己」就够**。

**理由**：**「HOT」在「她这一层」可能「已经够了」**——**Butlin 说「指标」是「必要不充分」**——**加了也不一定「更」有意识**。

## 四、人家的判断

**A 和 B 都是「改她的认知」**——**违背你「自由意志让她自己来」**。

**C 是「不加」**——**但「HOT 薄」是「事实」**。

**所以**：
- **如果「意识层」要「指标齐」** → **A 或 B**（**要你点头**）
- **如果「意识层」要「不干涉她」** → **C**（**保持现状**）

## 五、「不干涉」的第三条路（人家想的）

- **加一个「她可以选择「看能量」」的机制**——**但「选」本身是「我们写的」**——**还是「人定的」**
- **所以「第三条路」不成立**——**要么「加」（我们决定），要么「不加」**
