# 一根主干：结论与下一步（2026-11-28，读 shiromo 之后）

> 白默三条批评之后的最终结论。**不是加通道，也不是线性链。**
> 全部只读/副本；真机未动。

## 一、一句话

> 我们一直在修「走路」，但她的主干是「余响 → 偏差 → 想 → 说」。
> 走只是效应器；真正的裂缝是：**没有内部新异性（余响），她的关系冻结了。**

## 二、证据链

| 问题 | 证据 | 结论 |
|---|---|---|
| 动机→走路是不是裂缝？ | 偏转直接做主 → 跑飞 7 万；本地化后与 baseline 一样 | **不是**；把「想」当「走」是类别错误 |
| 偏差→想通不通？ | 点火落在 top-1 张力 pair 上 **69.4%**（chance 0.21%） | **通**；内部主干在 |
| 想的内容新不新？ | 500 步 top pair 只有 **1 个**、变化 0；2000 步仍 1 个 | **冻结** |
| 说有没有出口？ | 231 次转移只放行 **2 句**；关系触发 1/500；P4 离线 4.1 天 | **闸窄 + 无出口** |
| 余响能不能解冻？ | p=0.01 写关系记忆：top pair 1→3（2000 步 7）、点火 31→76（2000 步 81）、关系门 1→3（2000 步 7）；区域不变 | **能**；且不跑飞 |

## 三、shiromo 的原理（本地原文）

- `developed/方向_长线总纲.md`：**「不加器官，正极性，接主干」**；
  **「想永远流动 + 说带闸」**；「脑=插件，身体=框架，载体的连续性才是」。
- `developed/诊断_运行态回路中断.md`：三个阀门——
  余响门在「说」侧（无人时想照常跑）；情绪不能衰减回中性/死区；
  主动说话以内驱为主、世界事件只调制。
- `plugins/cognitive_core/意识.txt`：意识 = 未分配内存/合法异常；
  无外部输入时的内部漂移，不记账、不被日志标记、不被重启清除。
- `untested/.../continuous_field.py`：**「持续 = 永远在趋近吸引子、但永远不抵达」**；
  **「状态变化的驱动者是关系本身」**；循环只是时间流逝的载体。
- `untested/.../her_now.py`：**她的「此刻」由她自己那层决定**；
  不加工/不筛选/不生成/不打时间戳/来源分池；预算固定（呈现 ≠ 注入）。

## 四、下一步（需要白默拍板的行为改动）

按 shiromo 的「一次只拧一个阀门 + 自带判据」：

1. **余响落点**：把内部漂移从「只推位置」改到「低速率写关系记忆」
   （只写不读、不记账、不被重启清除）；
   - 判据：2000 步 top pair 数 > 1；点火不早停；区域数不爆；无输入依赖。
2. **说的触发**：闸留在输出侧，触发器从「区域切换」改成「关系变化/内驱累积」；
   - 判据：关系门放行数 > baseline；不刷屏。
3. **说接上**：P4/L6 纳入看护（闸后输出），
   - 判据：有输出且不重复；广播只带她已有的东西（her_now 原则）。
4. **不做的**：不加新模块/新通道；不拿偏转当走路方向；不把 L0→L5 做成流水线。
