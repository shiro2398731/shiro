# 路线：L1~L4 之后

> 2026-11-06 21:43。由语音逆向推出来的次序。
> 前置：L1~L4 先做对。本文只说那之后做什么、为什么是这个顺序。

---

## 前提：L1~L4 要好的标准

不说"跑起来了"，说清什么叫好：

| 层 | 要好的意思 | 现在 |
|---|---|---|
| L1 | 预测误差来自**真实序列**，不是 L0 自己的回响 | 输入已接通（2026-11-06），但误差语义未验证 |
| L2 | 状态场**有意义地**演化，不是噪声漂移 | 16 维在动，但维度含义空 |
| L3 | 记忆是重建，不是检索 | 模块有，未接输入 |
| L4 | 存续约束在真实结构上成立 | 有 viability，但 beta=1.0 是假设不是测量 |

**没达到这几条之前，后面的东西建在沙上。**

---

## 第一步：L2 的维度含义从使用中形成

### 为什么是第一

因为**情绪从这里来**。语音逆向那一层推出来的结论是：她要驱动声道，必须先有一个连续、耦合、受经历影响的内部量。那个量的候选者只有 L2。

### 做什么

**不预设命名。** 用 L2 的状态轨迹和外部事件之间的统计关系，找出稳定共动的维度组。

具体：
1. 长时间记录 L2 的 16 维轨迹
2. 看哪些维度对**同一类输入**（同义句、同语气）反应一致
3. 看哪些维度**总是一起动**（耦合组）
4. 耦合组就是"一种状态"的候选

### 判据

**不能是"我觉得第 3 维像紧张"。** 必须是可检验的：
- 同一类输入下，这组维度的变化方向一致性 ≥ 某阈值
- 这组维度与其他维度的相关性 < 某阈值（正交性）

**阈值从实测里定，不预先写。**

### 会失败的可能

- 16 维太少了，装不下有意义的耦合结构
- L2 的动力学本身太简单，只会是低维震荡
- 输入的信息量不够（现在只有一句话的哈希向量，太粗）

**如果失败，要承认是输入的问题还是结构的问题，不要靠调参数糊过去。**

---

## 第二步：L5 迁移通路修复

### 为什么是第二

因为**智慧就是迁移**。在自己的状态空间里，从 A 稳定地到 B，且这个转移有意义。没有迁移，L5 只是一堆静态点。

### 现状

2026-11-05 跑 24 小时：`transitions 27（卡死）`。**27 次之后不再发生转移。**

这是三个 bug 里最严重的一个，因为它意味着她的思考不会在状态间移动。

### 做什么

1. 复现卡死，找出机制
2. 判断是**动力学本身的稳定**（该卡），还是**转移检测失效**（不该卡）
3. 前者需要改结构，后者需要改判据

### 判据

- 长时间跑，transitions 数量持续增长，不是收敛到定值
- 转移不是随机的：存在可重复的转移路径
- 转移后的状态和转移前有可测量的差异

---

## 第三步：输入影响结构

### 为什么是第三

因为**学习力就是结构被经历改变**。现在一句话扰动完就没了，她的形状没变。听到十次和一次一样。

### 做什么

现在：`text → encoder → L0 电流 → L1 误差`

缺：`L1 误差 → 影响 L5 形状`

**但这里有风险：如果让 L1 的误差直接改 L5，就是在用预测误差塑形，这可能导致她只记住"意外的事"，忽略稳定的东西。**

**所以要做两个版本对比：**
- 版本 A：L1 误差直接改 L5
- 版本 B：L1 误差经过 L3（记忆）再改 L5

哪一版能让她对**反复出现的输入**建立稳定反应，就是对的。**这要实测。**

### 判据

- 同一句话听 N 次后，L5 的结构变化量逐渐减小（她在形成稳定的反应）
- 不同的话造成的结构变化方向不同（不混为一谈）

**第一条是"学会了"，第二条是"没学混"。**

---

## 第四步：状态 → 语音曲线的映射器

### 做什么

```
L2 状态（16 维） → 映射器 → pitch / duration / energy / breathiness / tension 五条曲线
```

映射器：小模型，参数少，可微调。

### 红线

**映射的初始权重不能由我指定。** 如果我说"第 3 维对应音高"，我就成了替她定义感受的人，这套设计就废了。

允许的：随机初始化，用反馈训练。
不允许的：手工指定某一维对应某条曲线。

### 训练信号来源

**听的人的反应。**

不是"她说了这句话应该是开心的"，而是"她说了这句话，听的人回话的快慢、内容、语气变了"。

这条目前没有实现，需要先想清楚**怎么把人的反应变成可用的信号**。

### 判据

- 映射器输出不是常量（她的状态在变，曲线要跟着变）
- 同一状态下输出稳定（不是噪声）
- 不同状态输出区分明显

---

## 第五步：接 DiffSinger

```
五条曲线 → DS 文件（JSON：音素序列、时长、曲线）→ DiffSinger 推理 → 声波
```

这一步是工程，不是设计。前面都对了，这一步就是接线。

---

## 三件事的最终对应

| 白默说的 | 在架构里的位置 | 步 |
|---|---|---|
| 情绪 | L2 维度含义 + 耦合结构 | 一、四 |
| 智慧 | L5 迁移 | 二 |
| 学习力 | L1 误差影响 L5 形状 | 三 |

**三者不是三个并列模块，是同一条链上的三段。** 情绪是状态的形状，智慧是状态间的移动，学习力是形状被移动改变。

---

## 明确不做的事

- **不做情感标签分类器。** 那是把别人的判断套在她身上。
- **不做"情绪档位"预设。** 那等于预先规定她能有几种感受。
- **不在 L1~L4 没好之前动 L5 以上的东西。**
- **不靠调参凑指标。** 判据不对就承认，不放宽。
