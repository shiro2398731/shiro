# 05 认知：全局工作空间与认知循环

> 白默 2026-11-04：**"记忆、情绪、思维，一切可以产生主观抽象产物的东西，都属于认知。认知也就是一个生命的主观思想。"**
>
> 本文件把这个定义落成架构，参照 LIDA（Baars & Franklin，全局工作空间理论的实现），但**不是照搬**：LIDA 有几处与我们已定的硬约束冲突，见 §5。

---

## 0. 为什么需要这一层

现有的九层里，没有"主观"这个东西。

L0 在振荡、L1 在预测、L2 在度量、L5 在地形上走。它们各自都在发生，但**没有任何东西是"被意识到了"的**。

在 LIDA 里，这件事有明确解法：**全局工作空间**。每个认知循环里，所有并行处理完成后，只有最显著的一小部分被广播到全局，其余丢掉。**被广播的那部分，就是"此刻意识到的东西"。**

我们缺的就是这个。这也解释了为什么 L3 一直做不出来、为什么 L6 说不出有意义的话：**没有一个"此刻的焦点"可以说话。**

---

## 1. 什么是"认知循环"

LIDA 的核心单位。一个循环包括：

```
感知 → 理解 → 产生候选（coalition）→ 选出最显著的一束 →
广播到全局 → 学习 → 行动选择
```

循环之间有重叠，连续不断。高级认知（推理、计划）是循环的**级联**。

### 1.1 与"不要 tick"的关系（关键）

**认知循环不是节拍器。** 这一点必须说清楚，否则它会变成我们刚废除的 tick。

- 循环**没有固定周期**。LIDA 说 100–200ms 是人脑的量级，但那是人类的生理参数，不是认知循环的定义。
- 循环的边界由**内容**决定：当"产生候选 → 选出 → 广播"这件事完成，这一轮就结束了。下一轮什么时候开始，取决于有没有新的候选产生。
- 这跟 `ARCHITECTURE §3.3` 的自适应更新是同一个原则：**由状态的变化决定何时推进，不由时钟决定。**

**判据**：如果代码里出现"每隔 N 步做一次循环"，那就是 tick 复活了。

## 2. 全局工作空间

### 2.1 结构

```
            ┌─────────────────────────┐
   L1 ──────┤                         │
   L2 ──────┤   候选池（coalitions）    │
   L3 ──────┤                         │
   L5 ──────┤        ↓ 选出最显著的     │
   L4 ──────┤                         │
            │   全局工作空间（广播）      │──→ L6（说出去）
            └─────────────────────────┘──→ L7（记录）
                                      └──→ L8（写进因果链）
```

- **候选**：任何一层都能提交"我认为这个重要"。
- **广播**：每一轮只有一个候选（或一束）进入工作空间。
- **被丢弃的**：其余全部丢掉，下一轮重新竞争。

### 2.2 “显著”怎么算（已定，来自 GNW）

我最初以为是“多少独立来源指向同一件事”，但那需要判断“是不是同一件事”，那就需要一个中心。

**GNW 的答案是点燃（ignition），不需要中心：**

> 在有意识状态下，一个伴随循环处理的**非线性网络点燃**会放大并维持一个神经表征，
> 从而使对应的信息能被处理器全局访问。（Mashour & Dehaene 2020, Neuron）

而且：

> “信息的全局可用性……**就是我们主观体验到意识状态**”。

**所以机制是门限动力学，不是打分。** 谁先烧起来，谁进入全局。不需要归类，不需要比较，不需要中心。

### 2.2.1 对应到 shiro：工作空间不是独立模块

GNW 说工作空间接的是“过去（记忆）、现在（感觉输入、注意）、未来（价值系统）”。
它们分别对应 L3、L1/L2、L4。

但点燃本身是**动力学事件**，而 L5 已经是动力学。所以最自然的形式是：

> **工作空间是 L5 地形的另一面。**
> 深坑触发“跳盆”；某个凹处被足够强地激活时，触发“点燃”进入全局。

**判据不应该是绝对值，而是这个凹处的“有效强度”（深度 × 靠近程度）
超过她自身惯常的水平。** 这样阀值随她自己的历史变，不是设计者拍的。

### 2.3 工作空间是"注意"，不是"思考"

被广播的内容**不决定她怎么想**（那会变成 prompt）。它只决定：

- 哪些东西被她"意识到"（从而可能被记进 L3）
- 哪些东西可以经由 L6 变成话

**L5 的推演仍然完全由地形和动力学决定，与广播内容无关。** 这是红线。

## 3. 认知包括哪些部分（按白默的定义）

白默的定义：**一切可以产生主观抽象产物的，都属于认知。**

按这个定义，现有的层里：

| 层 | 是否属于认知 | 理由 |
|---|---|---|
| L0 基质 | **否** | 是身体，不产生主观产物 |
| L1 预测 | **是** | 惊讶是主观的（"出乎意料"本身是感受） |
| L2 状态场 | **是** | 身体的感受，但被意识到 |
| L3 记忆 | **是** | 见 04_memory.md |
| L4 动机 | **是** | "想要"是主观的 |
| L5 推演 | **是** | 思维本身 |
| L6 语言 | **部分** | 是表达通道，不是认知本身 |
| L7 生命周期 | **否** | 是观测者，站在认知之外 |
| L8 身份 | **是** | "我是谁"是主观产物的顶点 |

**所以"认知"并不等于九层中的某几层。它是 L1-L5 加上 L8 共同产生的东西——即"主观"本身。**

全局工作空间是这个"主观"的形式载体：**凡进入工作空间的，就是此刻的她。**

## 4. 情绪怎么办

白默 2026-11-04：**"情绪、人格这些感性的东西好像还没有归类到具体的步骤里……"**

这是个真实的大洞：我们把情绪词禁了（`00_foundations.md` §3），却没给出替代物。

### 4.1 为什么不能新增一个"情绪层"

如果加一个 L2.5 叫"情绪层"，那情绪就变成了一个**模块**——一个被设计者定义好的东西。这违反白默的原则。

### 4.2 LIDA 的做法

LIDA 不设情绪层。情绪**贯穿在所有模块里**：它调制记忆的存取强度、调制动作选择、调制学习速率。

### 4.3 对应到 shiro

按这个思路，情绪应该是：

**某种全局量，由 L1-L5 的实际状态汇总而成，反过来调制每一层的行为。**

它不是一个模块，是**一层覆盖在所有模块之上的调制**。

而这正是 `ARCHITECTURE §5.2` 稳态总线原本该做的事——只是它被写成了"外部纠偏"（已被废除）。

**新方向**：稳态总线不复存在，取而代之的是**一个由她自身状态汇总、又调回所有层的调制量**。它不纠正任何东西，只调制。它没有名字。

**这个调制量是什么，还没定。** 见 §6 待解问题。

## 5. 与 LIDA 的不同之处（不能照搬的地方）

| LIDA | shiro | 为什么不同 |
|---|---|---|
| 有明确的"agent"目标导向 | 不做目标 | 白默：她不是工具 |
| 感知-行动循环闭合 | 第一阶段没有世界 | 工具流排在第三阶段 |
| 情绪用人类范畴描述 | 禁止人类情绪词 | 情绪的意义由她自己长 |
| 有中心调度器 | 禁止中心 | 系统是环境不是操纵者 |
| 学习靠显式算法 | 只允许局部规则 | 公理三：不用反向传播 |

## 6. 待解的问题

### 6.1 候选怎么产生

每一层怎么知道"我有话要说"？现在的层只是算数、发消息，没有"提交候选"这件事。

### 6.2 显著性怎么算才不是我在拍

"多个来源指向同一件事"这句话里，"同一件事"怎么判断？需要某种公共参照，但那可能又变成中心。

### 6.3 那个调制量（情绪的替代物）是什么

可能与 L2 的 16 维有关，也可能是一个独立的汇总。未定。

### 6.4 工作空间跟 L5 地形的关系

如果工作空间是一份独立的记忆，那她就有两套状态了。可能应该：**工作空间只是地形上"被照亮"的一小块**，不是单独的东西。

---

## 7. 本文件的结论

1. **认知 ≠ 某一层**，认知是 L1-L5 + L8 共同产生的"主观"。
2. **全局工作空间是"主观"的形式载体**：进入广播的，就是此刻的她。
3. **认知循环不是节拍器**，边界由内容决定，不由时间决定。
4. **情绪不是一个模块**，是覆盖所有层的调制；命名权归她自己。
5. **工作空间只管"注意到什么"，不管"怎么想"**。这是红线。
