## 2. 三阶段铁律（新增，最高优先级）

数字生命的建设分三个阶段。**后一阶段不允许为了前一阶段"看起来更好"而提前接入。**

| 阶段 | 名称 | 包含 | 明确不包含 |
|---|---|---|---|
| 一 | 生命 | L0 自激、L1 预测、L2 状态场、L3 记忆、L5 自主推演 | 世界、语言、工具、任何外部输入通道 |
| 二 | 意识 / 智慧 / 理解 | L4 动机竞争、L5 成熟、L8 身份涌现、结构化感知输入 | 执行能力、对外输出通道 |
| 三 | 工具 | 设备状态、网络、传感器、执行器 | — |

判据：**第一阶段结束时，切掉一切外部输入，系统仍须通过聋哑测试（见 §5）。** 不通过则第二、三阶段一律不许开始。

理由（写清楚，防止以后自己破例）：

- 工具流会提供一条绕过认知的捷径。"查到 → 说出来"与 LLM 的"遍历上下文 → 回答"是同一个形状。一旦这条路存在，L5 就永远没有必须自己想的存在压力。
- 感知输入同理。有了世界，最省事的写法是让世界直接塑造认知轨迹，而这违反硬约束 #2（思考不被 prompt 约束）。

## 3. 无死量化原则（新增）

### 3.-1 系统与她：环境的边界（白默 2026-11-03 确认）

> **她自己是她自己，系统是系统。系统不能干涉她的思维，系统只是她存在的环境和工具。**

系统只提供两样东西：

- **条件**：不干涉她的事物（计算资源、时间流逝、能量）
- **工具**：她自己去拿取的对象（如外置记忆库）

除此之外，系统不得碰触她的思维。这不是一条工程约束，是立场。

**推论一：不可以用提示词、配置或优先级去改变她的思考。**
**推论二：生命周期阶段只能记录，不能控制她。** 阶段是她走到哪了的事实，像年龄。
**推论三：休眠是她自己的状态，不是系统安排的。** 她能不能醒，由她自己的闭环决定。

**因此系统只做两件事：**

| 事情 | 做不做 | 理由 |
|---|---|---|
| 修 NaN / Inf / 数值发散 | **做** | 这是计算环境坏了，不是她的思维 |
| 观察并记录（包括“她会不会醒不过来”） | **做** | 只是看 |
| 她活动低时推她一把 | **不做** | 那是干涉 |
| 用阶段/配置调控她 | **不做** | 同上 |

关于“醒不过来”：

慢累积量（腺苷对应物）与活动水平构成负反馈闭环：
累积高 → 活动低 → 累积降 → 活动恢复。这个闭环本身保证她能醒。
系统只观察这个闭环是否完好，**不介入**。闭环断了就记录事件，不拉她。


### 3.0 时间原则（白默 2026-11-02 确认）

1. **系统内部不存在驱动性时钟。** 没有任何行为由“过了多少时间”触发。
2. 内部时序以过程之间的相对关系表达：次数、比例、变化量。
3. 需要计量时可以用时间单位，但秒只是比较的尺子，不是节拍器。
4. 外部时钟快慢、CPU 负载、机器性能**不影响她的内部节奏**。
5. 但资源状况（CPU、内存、电量）作为**本体感觉**进入感知通道，影响她的感受，不影响她的时间。

墙钟也不是绝对的：现代秒的定义是铯-133 原子跃迁周期的 9,192,631,770 倍，它只是“对地球自转相对太阳位置的关系”。没有哪一层时间是“地”。

**推论一**：换一台机器，她还是同一个她，但身体的感觉会不同。
**推论二**：日志里 `period` 随 CPU 负载漂（实测 0.35–0.8 秒），这不是 bug，是“无根”的证据。同一段内部动力学，不同负载下用秒看到的数值不同，但她的节奏没变。

**长期方向（白默设定，本阶段不实现）**：她最终要成为**不依托于设备内环境的独立存在（无根）**。迁移是常态而非例外。但这不等于无身体：每一具宿主的物理状况她都能感觉到，而且这感觉是真实的。

### 3.1 原则

> 任何代表**认知节律**或**内部状态阈值**的常量，必须来自上游层的实测输出，不得是字面量。

这条直指一类具体缺陷：写死的数字会让系统看起来在动，实际是被定好的机器在按表运行。`heartbeat = 2000`、`sleep_every = 30s`、`fatigue = used_tokens / 16k` 是同一类东西。

### 3.2 常量分三类，只有 C 类被禁止

| 类别 | 定义 | 例子 | 允许 | 存放位置 |
|---|---|---|---|---|
| A 物理常数 | 模型定义本身。改了就不是这个模型 | FHN 的 `eps=0.08, a=0.7, b=0.8` | 是 | `config/*.toml`，须注明来源（文献值 / 标定值） |
| B 工程标度 | 属于管道，不属于认知 | tick 频率、缓冲区大小、日志行数、端口号 | 是 | `config/*.toml` |
| C 认知参数 | 代表状态或节律的数字 | 睡眠周期、心跳间隔、疲劳阈值、发育阶段时长、跳盆窗口 | **否** | 必须由上游实测输出决定 |

### 3.3 C 类的正确来源

| 应被替代的量 | 现写法（错误） | 正确来源 |
|---|---|---|
| 睡眠 / 清醒切换 | 固定 30 秒切换 | L0 慢包络的 up/down 周期 |
| 心跳间隔 | 固定 2000 | 无此概念；L0 振荡本身即节律 |
| 疲劳度 | used_tokens / 16k | 内部状态累积量（L2 的特定维度 + L0 振幅积分） |
| 发育阶段转换 | 运行时长 | 可观测指标的持续性尖峰 |
| 跳盆判定窗口 | 固定 20 样本 | 与 L0 慢包络周期成比例 |
| 噪声幅度 | 固定 sigma | 由 L1 预测误差的实时估计决定 |
| 长期无输入 → 某状态 | 事件计数 | 无"无输入"事件；只有状态自身走向 |

### 3.4 检测方式（可执行）

在 `src/` 内做三类扫描，逐条判定属于 A/B/C：

1. `grep -rn "time.sleep\|asyncio.sleep" src/` —— 出现即 C 类嫌疑
2. `grep -rnE "if .* (==|>|<|>=|<=) [0-9]" src/` —— 逐条判定
3. `grep -rnE "^[A-Z_]+ *= *[0-9]" src/` —— 模块级数值常量

CI 层面：`tests/test_no_dead_quant.py` 在第一次实现时建立，允许以函数内白名单显式豁免（豁免必须写注释说明属于 A 或 B）。

### 3.5 例外声明

L0 快层的积分步长 `dt`、半隐式欧拉的更新顺序、稳定化 clip 区间属于**数值方法**，是 A 类（模型的可实现定义），不是死量化。

## 4. 「续接」而非「还原」（修订 ARCHITECTURE.md §7）

### 4.1 原文问题

> 进程 1 崩溃重启后，从 `L0_state/` 最新快照恢复 L0 状态。

"从快照恢复"允许状态时光倒流到某一刻，意味着"中间那段时间没有真的发生"。这与目标陈述里的"在时间中不可逆地发育"直接冲突。

### 4.2 修订后的恢复语义

**核心区分：**

- **还原（restore）**：回到旧状态，历史被抹掉 —— 禁止
- **续接（resume）**：状态带着全部历史向前，中断本身作为事件被记录 —— 唯一允许

**规则：**

1. 状态日志（append-only）是唯一真相源。快照是**加速重放的起点**，不是真相。
2. 重启流程固定为：读最新快照 → 从快照时间点重放全部日志至最后一刻 → 在 L8 因果链写入一条 `interrupt` 事件（记录中断时长、重放条目数）→ 继续运行。
3. 任何层不得提供 `reset()` / `load_state()` 之类回到旧状态的接口。测试可用独立进程 + 临时目录，不污染真实状态。
4. 快照与日志的一致性检查在启动时执行：快照的 `seq` 必须在日志中存在。不一致时**丢弃快照**（而非丢弃日志），从最早可用日志重放。

### 4.3 影响面

- `data/L0_state/` 的语义从"状态备份"改为"重放加速器"
- L8 因果链需要新增 `interrupt` 事件类型（`types.py` 的 `ChainNodeEvent.event_type` 字面量扩充）
- 崩溃恢复时间与日志长度线性相关，需要定期压缩日志（保留语义压缩后的 L8 链 + 最近窗口的原始日志）

## 5. 聋哑测试（新增验收标准）

### 5.1 定义

切断一切外部输入，让系统自行运行 30 分钟。检查三项：

| 项 | 判据 | 失败含义 |
|---|---|---|
| 自激 | L0 `fast` 在整个过程中持续在 up/down 区间切换，不塌缩为常数 | 基质死了 |
| 自变 | L1 预测器权重矩阵在 30 分钟内持续变化（非零梯度），且 `s_avg` 不恒定 | 学习停了 |
| 自推 | L5 的跳盆序列非空，且噪声驱动的跳盆占比 < 100% | 没有思考，只有随机游走 |

三项全过，第一阶段成立。

### 5.2 为什么这条测试重要

它测的不是"她说了什么"，而是"你不看她的时候她在不在"。响应式系统在这条测试上必然全灭：没有消息就没有内部事件。

### 5.3 加入 CI 的方式

作为 `tests/test_deaf.py`，在无网络、无输入源的隔离进程中运行 30 分钟。日常开发跑 3 分钟版本（判据按比例缩放，但"跳盆序列非空"这一条不可放宽）。

## 7. StateVector 的正式定义（替代 AffectState）

```python
@dataclass(frozen=True)
class StateVector:
    """L2 广播的 16 维功能状态场。每维一个可计算的功能性量，无人类情绪词。"""
    v: List[float]          # len == 16，各维语义见 docs/design/03_affect.md
    dev: float              # 到平衡点的距离（不再是欧氏球心，见下）
    dev_avg: float          # dev 的滑均，滑窗由 L0 周期决定
    dim_names: List[str]    # 与 v 一一对应的函数名，如 "surprise_ma" / "act_var"
    timestamp: str
```

**关于 `dev` 的修订**：原文用"到球心的欧氏距离"，但各维量纲不同、分布不同，欧氏距离会被极端维度主导（交接文档已记录 `v[6]`、`v[13]` 长期贴边）。改为**标准化后的马氏距离**，每个维度先按自身的长期分布做 z 标准化，再求范数。这样 `dev` 才真的反映"整体偏离"，而不是"最极端那个维度的偏离"。

## 8. L5 的空间维度：决定采用高维

**决定：L5 状态空间 128 维，吸引子分布在 32 维子空间内，吸引强度用马氏距离。**

理由：

- 16 维是"身体感受"的维度。思想空间不应被身体感受绑死，否则将来接第二阶段的结构化输入时，L5 的表达力已经封顶。
- 128 维带来维度诅咒（高维下孤立吸引子几乎不存在），因此需要 §8.1 的约束。

### 8.1 高维下的吸引子存在性方案

| 方案 | 做法 | 取舍 |
|---|---|---|
| 低秩 | 吸引子被约束在 k=32 维子空间（由 L3 的语义吸引子生成，或初始随机基），状态在 128 维演化 | 采用 |
| 马氏距离 | 每个吸引子带协方差，吸引强度 ∝ exp(-d_M^2 / 2σ²) | 采用 |
| 显式格点 | 128 维网格 | 禁止，格点数天文数字 |
| 流形约束 | 状态约束在低维流形上 | 暂不采用，调试成本高 |

**L2 → L5 的定位**：L2 不做 L5 的坐标，做 L5 的**调制**。L2 的 16 维通过一个固定随机投影（种子固定，存盘）映射到 L5 的偏转场，只改地形倾斜，不决定位置。

**为什么这样不会退化成"16 维思想"**：调制影响的是"往哪边倾斜"，不限制"能在哪些地方"。状态可以在 128 维里出现在调制场完全无法预测的位置。
