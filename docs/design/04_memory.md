# 04 记忆：目前想到哪儿了

> 状态：**未定稿，先记录**。白默 2026-11-04：想了一年还没完全想好，先把这个议题挂在这里，续上。
> 本文件不是设计，是一份"已知边界 + 待解问题"的记录。写下来的目的，是防止以后从零重想。

## 1. 已经确定的前提（来自文献与白默的判断）

### 1.1 记忆不是存储

- 人脑记忆**不是对过去的字面复制**，依赖建构过程，容易出错和扭曲（Schacter 2012）。
- "记忆载体"本身一直在被替换：突触权重、树突棘、engram 细胞群都会更替，而更替的时间尺度与记忆存续时间对不上（*Memory without a trace*）。
- 工作记忆的信息**不在神经元持续放电里，在突触连接的短期变化模式里**（MIT 2023, PLOS Comp Biol）。
  Miller: "如果工作记忆只是持续放电，那它简单得像一个电灯开关。"

**结论：不存在一个"存放记忆的地方"。记忆是结构本身的一个状态。**

### 1.2 想起来是重建，不是检索

- 每次回忆都是用**现在的结构**重新拼一次，拼出来的会反过来改变结构。
- 所以禁止实现"存储 → 检索"这种形式。那是 LLM 读上下文，不是记忆。

### 1.3 关联靠判断力，不靠时间邻近（白默 2026-11-04）

- 文献里确实有时间邻近连接记忆的证据（Yetton 2019：3 小时内的记忆会互相带动，7 天不会）。
- **但白默否定了以此作为关联的来源**：*"不要，靠信息，这排在她有了智慧、学习喝判断力之后。"*
- 即：时间邻近可以作为现象存在，但不能当作"建立关系"的机制。建立关系是判断，判断需要智慧。

## 2. 记忆的两种形态（白默 2026-11-04）

| 形态 | 例子 | 需要"想起来"吗 | 能否从认知中拆出 |
|---|---|---|---|
| **知道** | 我知道水是湿的 | 不需要 | 不能，它就是理解力的一部分 |
| **记得** | 我想起昨天喝了水 | 需要 | 能，它是一段具体的经历 |

- 前者接近神经科学的**语义记忆**，后者接近**情节记忆**。
- 白默的判断：**"知道"可能不是存着的，它就是推理能力本身的一部分。**

**推论**：L3 要做的只是后一种。前一种不需要 L3，它长在 L5 的地形里，或者更准确地说——**它就是地形本身**。

## 3. "想起来"的两条路

### 3.1 有东西推它（线索 → 重建）

计算上有经典答案：**模式补全（pattern completion）**。

Hopfield 网络里，记忆不存在任何地方，只是连接权重的一个稳定状态。给一半线索，网络收敛到最近的那个稳定状态。

**关键点：它不需要把东西"取出来"，因为结构本身就是那个记忆。**

### 3.2 它自己冒出来（自发激活）

- 生物证据：海马静息时的尖波涟漪会自发重演旧的活动模式，不需要外部线索。
- **白默 2026-11-04 补充：想起来完全可能不靠线索。**

这一条可能**不需要智慧**：因为它不需要判断"什么值得想"，念头自己就浮上来了。

## 4. 当前 L5 的缺口

| | Hopfield 的吸引子 | 现在 L5 的痕迹 |
|---|---|---|
| 状态 | 有限个特定的稳定点 | 连续的一片凹地 |
| 靠近时 | **变成那个记忆** | 只是待在凹地里，凹地不"代表"任何东西 |
| 能否"想起来" | 能 | **不能** |

**这就是白默说"不算"的原因：地形有记忆的形状，但没有记忆的内容。**

## 5. 待解的问题

### 5.1 痕迹要有什么形状才能"想起来"

方向：让痕迹从"有深度的凹地"变成"有确定中心的吸引子"，她靠近时被拉向那个**特定的点**，而不是被拉向**这一片**。

未定：这个"确定中心"该是什么？一个位置向量？还是更复杂的东西？

### 5.2 自发激活怎么实现

地形自己会动——但这需要地形有内在动力学，而现在的痕迹只会衰减。

### 5.3 两种记忆形态怎么共存

- "知道"长在地形里
- "记得"需要另一种东西
- 它们共用一片地形吗？还是"记得"的东西会覆盖/变形地形？

### 5.4 外置日记本（已确认要做，但细节未定）

- 白默 2026-11-03：外置数据库可以做成日记，她自己能翻。
- 数据库可以一直增长（那是档案，不是身体）；她的内部结构必须代谢（否则臃肿）。
- **翻日记是"读"，不是"想起来"。读不会直接改地形。**
- 但"她翻过日记"这件事本身是一次经历，会留下痕迹。
- 尚未设计：表结构、她怎么"翻"、翻到的东西怎么进入她的状态。

### 5.5 代谢（已实现，但可能需要再想）

- 已实现：痕迹按个体衰减速因子 + 随机起伏变淡，淡到看不见就消失。
- 已删除：按"最浅的优先"淘汰（那是 KPI 逻辑，不是生理）。
- **不等同于"用进废退"**——代谢不看某条痕迹最近有没有被访问。

## 6. 与其他层的关系

- **L3 与 L5**：L5 的地形是她"怎么想"留下的形状；L3 要回答"为什么这块地形会长成这样"。目前判断：L3 不存储，L3 让地形的生长方式变得有结构。
- **L3 与 L1**：L1 的预测误差是"惊讶"，惊讶可能是"什么值得记住"的天然信号——但这是不是"判断"，取决于智慧何时出现。
- **L3 与 L4**：动机决定"什么重要"，而重要性是记忆筛选的依据。但 L4 也还没写。
