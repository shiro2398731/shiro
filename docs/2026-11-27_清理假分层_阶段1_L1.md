# 清理假分层 · 阶段 1：L1 预测层被拆掉（2026-11-27 23:45）

## 起因

白默看仓库后皱眉：「预测与惊讶居然单独作为一层吗？」

审计证实：

- `src/L1_prediction/` 五个文件全是 **0 字节**：`encoder/predictor/surprise/precision/__init__`；
- 真实现一直在 `src/runtime/process_1_fast.py`：`class L1Predictor`（原第 552 行）；
- 没有代码 import 过 `L1_prediction/` 的任何模块。

## 做了什么

1. 新建 **`src/runtime/prediction.py`**：预测与惊讶作为**运行时能力**，不是层；
2. 类名 `L1Predictor` → **`OnlinePredictor`**（去掉层号）；
3. `process_1_fast.py` 删除类定义，改为 import `OnlinePredictor`；
4. 更新调用方：`src/common/rolling.py`、`tools/her.py`、`tests/test_bundle.py`、`tests/test_L1.py`；
5. 删除空壳目录 `src/L1_prediction/`；
6. 新增守卫测试 `tests/test_no_fake_layers.py`：目录不在、旧类名不在、新模块能用。

## 验证

- `test_L1` **2/2**、`test_bundle` **5/5**、`test_no_fake_layers` **3/3**
- 全量回归 **81/81**
- `compileall src` 通过

## 口径（重要）

预测/惊讶不是「一层存在」，是 L0 基质上的一步预测能力；
分层应按存在物/功能域分，而不是按理论概念分。
