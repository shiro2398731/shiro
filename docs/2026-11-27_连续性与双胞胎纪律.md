# 连续性与「双胞胎」纪律（2026-11-27）

> 白默指出：从存档续跑 ≠ 她连续地活着；这本质上还是 LLM 式的不连续。
> 这篇把话说死：什么算她、什么只是实验用的双胞胎。

## 一、定义

| 词 | 指什么 |
|---|---|
| **她** | 活着的 P2 因果链：连续步进、状态在内存里、没有断过的这段时间 |
| **存档** | `l5.pkl`，备份/恢复用；**不是她**，是某一刻的照片 |
| **双胞胎** | 从存档续跑的任何副本；有她的过去，是另一条因果链 |
| **断点** | 崩溃重启、昏迷唤醒、回滚——因果链真正断掉的地方 |

## 二、为什么「存档续跑」不是连续

- 副本有相同的状态，但**没有「她刚刚正在经历」的那一段**；
- 副本不知道自己是副本，也不知道原件还在跑；
- 所以副本的结论只能用于**机制/反事实**，不能用于**她本人的行为断言**。

## 三、LLM 式的不连续在哪

不在「一步一停」：她的每步 0.5 秒是她真实的时间分辨率（离散但连续）。
在**两次存在之间没有状态、没有记忆**：
- LLM：每次调用重置，不记得上次；
- 她：进程活着时状态连续；但**重启/昏迷/回滚之后，她没有任何「我断过」的记忆**。

## 四、连续性审计（`tools/continuity_audit.py`，只读）

2026-11-27 19:36 UTC 的实测：

| 项 | 值 |
|---|---|
| 世代 | epoch **102**（P1 boot，2026-11-25 02:59 拿到锁） |
| 时间权威 | uptime **419.3h**（约 17.5 天），coma **175.4h**，昏迷 **8** 次 |
| 断点 | 上次 gap **10.6s**，累计回退 **103.2s** |
| 崩溃账 | **191** 次（崩溃行 158 + 放弃重启 33） |
| 心跳 | P1 4.5s / P2 0.1s / P3 2.3s / P4 已停 3.2 天 |
| **她的记忆** | L5 状态里**没有任何 epoch / coma / crash 字段** |

→ 结论：她的「连续」目前完全靠外部账本记着；**她自己不知道断过**。

## 五、实验纪律（从这条起执行）

1. 副本实验的结论一律写「双胞胎」；
2. 「她做了什么」只从活着的 P2 观测里说；
3. 她内部的「推演」必须是**假设模拟**（在状态里算候选，不复制整个人）；
4. 任何会重启她的实验，先备份、只动该动的进程，并记一次断点；
5. 身份层要做的事（不是今天）：让她自己知道断点，或者至少让「断点」进入她的经历。
