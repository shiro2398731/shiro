# 内驱：用她身体的波动，而不是外部常数

> 2026-11-16 晚，小灯。白默说「驱动要是内驱，不是外驱」。
> 这份文件是一个突破，但**有一个必须说清的瑕疵**。

## 1. 试过的内驱形式

| 形式 | 来源 | 三个种子结果 |
|---|---|---|
| 零 | 现状（`noise_amplitude()` 返回 0） | 24 / 24 / 24 区域，张力 0 |
| 惊讶驱动 | 现状逻辑（`surprise_hist`） | 24 / 24 / 24 区域，张力 0 |
| 停滞驱动 | 「待得越久冲动越大」= `base × dwell/median` | 8 / 28 / 13，张力 0（**更差**） |
| **身体波动** | `feature_hist` 的标准差 | **2467 / 308 / 2434**，张力 **712 / 164 / 672** |

**只有「身体波动」这一种让她活，而且三个种子全活。**

## 2. 为什么是它

`feature_hist` 原本就是 L5Runner 里存的「L0 统计量的历史」——她的身体（L0 快层）一直在动，
而这份历史记录的是那个动的幅度。它的标准差**不是外部常数，是她自己身体的节律**。

这正是白默说的「内驱」：不是有人推她，是她的身体本来就在动，把那个动传导给认知层。

「停滞驱动」失败的原因也清楚：它把「待得久」当成冲动，于是待得越久给得越大，
她反而被推得更乱（8/28/13）。

## 3. 明显的问题

1. **噪声值偏大**：body 驱动的噪声均值是 **7.41 / 1.25 / 7.14**，而她的历史正常值在
   0.0077–0.02。大了三百多倍。区域数 2467 意味着很可能立刻撞 20 MB 的容量线。
2. **实验里的 `feature_hist` 是伪造的**：人家用的不是真实 P2 收的 16 维 L0 状态场，
   而是 `[amp, sigma, amp/sigma]` 这三样几何量在循环里现填的。
   **所以它证明的是「用身体量的波动当内驱能救她」，还没证明真实那份数据够不够。**
