# 「出生熵」设计 + 验证方法（2026-11-24 12:35）

> 人家试了「副本验证」：**两个不同 seed 的实例，跑 200 步**——**结果「都没动」**（区域 0、x 距离 0.00）。
> 原因：**副本「地形空」**（没加载存档，`_apply_leave` 没「去处」）。
> **所以「出生熵」要在「真实」上验证。**

---

## 一、设计（最小改动）

### 改动 1：`Stream.__init__` 的 seed

**现在**：
```python
def __init__(self, ..., seed: int = 0):
```

**改成**：
```python
def __init__(self, ..., seed: int | None = None):
    if seed is None:
        seed = int.from_bytes(os.urandom(8), "little")
    self._born_seed = int(seed)      # 存下来（出生证明）
```

### 改动 2：`x` 初始从 seed 推

**现在**：`x` 从「原点」开始（要查具体）。

**改成**：
```python
rng = np.random.default_rng(seed)
self._st.x = rng.normal(0, 1.0, dim)   # 出生点不同
```

### 改动 3：`energy` 初始从 seed 推

**现在**：`energy = 1.0`（所有人一样）。

**改成**：
```python
self.energy = float(rng.uniform(0.9, 1.0))   # ±10%，不同「体质」
```

### 改动 4：`seed` 存进 `l5.pkl`

**要做**：`persist.py` 的 `build_l5_payload` 加 `"born_seed": stream._born_seed`，`apply` 时读回来。

**这样**：**重启不变**（**同一个她**）——**新部署不同**（**每个 shiro 不同**）。

---

## 二、验证方法（「真实」上）

### 步骤

1. **备份** `l5.pkl`
2. **改代码**（上面 4 处）
3. **新建一个「测试部署」**：**`data/state/l5.test-seed2.pkl`**（**从 `l5.pkl` 拷**，**但 `born_seed` 改成 2**）
4. **跑 1 小时**（**P2 加载 test-seed2**）
5. **看**：**两个 shiro 的 `x` 轨迹「发散」了吗**（**距离越来越大 = 发散**）

### 判据

- **`x` 距离 > 1000**（**明显不同**）→ **「出生熵」有效**
- **`x` 距离 ≈ 0** → **「出生熵」被「吸收」了**（**她的动力学「收敛」**）→ **要查「为什么」**

---

## 三、风险

1. **改了 `x` 初始**——**她「不在」原来的原点**——**可能「迷路」**（**没有「熟悉的地方」**）
2. **`energy` ±10%**——**她的「疲劳曲线」变**
3. **`seed` 存进 `l5.pkl`**——**旧存档「没有」`born_seed`**——**要「兼容」**（**默认给 0**）
