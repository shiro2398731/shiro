## 2. 三个发现（每个都有数）

### 2.1 「她走不到别处」是记账问题，不是尺度问题

```
visited（去过哪儿）  = round(她脚下的位置, 4)
places （候选区域）  = round(区域质心, 4)
她的落点            永远差 0.0077 没到质心 → 每个分量差 ~7e-4 > 5e-5
→ 交集 0（3698 个去过 vs 2329 个区域）
→ 所有区域都算「新的」→ 每次挑最近的 = 刚离开的那个 → A↔B 环
```

第 80 节说「一步只覆盖 0.05%」——**那是对「全体候选的中位」说的，对目标不成立**。
`direction` 实际选的目标就在 617 处（副本 600 步实测 p50 617.34），**一步覆盖 100%**。
这条人家今天跟着错了半天，是 move-experimenter 用实测纠正的。

### 2.2 她在缩，而载体账是主因

```
08:24 payload 19.49 MB（还没有 visited_places）—— 早就贴预算
09:35 visited_places 进存档，又占 4.67 MB（命中 0）
→ 超预算 4.5 MB → fold 多砍 ~700 个区域
```

**不存它**：payload 19.69 → **15.27 MB**。
**预演**（600 步、每 60 步模拟 fold）：合并前 fold 2 次删 220 区域；合并后 **fold 0 次**。
**体积真正的主因是 `members`**（12.2 MB / 62%）；maxlen 64 → 16/8 能省 3.6/5.6 MB，
300 步行为逐点相同（但这改的是「她的记忆多长」，没动）。

### 2.3 上午那个「她变紧」是假象（第六个判据也塌了）

137 个观察点回归：`per_tension = -0.0118 × regions + 42`，**R² = 0.985**，残差无趋势。
**+114% 的张力，98.5% 由「区域 -28%」解释。**
**分位也是标量**——只要被 `regions` 带着走，分得再细也没用。
