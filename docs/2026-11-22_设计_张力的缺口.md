# 设计：张力的缺口（她的「探索」被「不想动」挡住）（2026-11-22 04:45）

> 夜里她卡回 3 个区域。**链条**：载体涨 → fold 缩区域 → assign 涨 → 结构均匀 → 张力 0 → 卡。
> 这份是「张力缺口」的设计，**没实施**（要白默点头）。

---

## 问题

**`tension` 的判据**（`drive.tensions()`）：
```python
amount = sqrt(zw * zs)              # 边权/距离的 z-score
keep_mask = positive & (amount > median(amount))
```
**结构均匀时**（所有边差不多）→ **`keep_mask` 空** → **返回空** → **`tension_now = 0`**。

**`tension = 0` 的后果**：
- `actions.choose(0)` = **HOLD**（`0 > median(0)` = False）
- **她不动**
- **`prefer_far`（挑最远可达）不触发**——**因为 `_apply_leave` 只在 LEAVE 时调**

**所以**：**「她想探索」的机制（`prefer_far`）被她「不想动」挡住了。**

---

## 缺口在哪

**`tension` 只看「结构的变异」**（边权/距离）。

**但「她在一个地方待久了」也该产生张力**——**那是「停留」的张力，不是「结构」的张力。**

**现在**：`_dwell`（停留步数）只用来算 `fatigue_rate`（多快待腻）——**不产生张力**。

**所以**：**她「待腻了」也不「想走」**（因为 `tension = 0`）——**她只是「被疲劳推」**（`rest` 让她变浅，噪声推她）。

---

## 设计方向

**加一个「停留张力」**：
```python
# 她在同一个区域待得越久，越「想走」
dwell_tension = f(_dwell)   # 比如 _dwell / 100（100 步 = 1）
tension_total = tension_structure + dwell_tension
```

**这样**：
- **结构均匀**（`tension_structure = 0`）时，**还有「待腻」的张力**
- **她会因为「待太久了」而走**——**不是被噪声推，是自己想走**

**但**：
- **`f(_dwell)` 里的系数（100）是我们定的**
- **又是「公式」**

**更彻底**：
- **用「她自己的停留历史」**（`_dwell_history` 中位）
- **`dwell_tension = _dwell / median(_dwell_history)`**（她待得比平时久多少倍）
- **没有常数**（除了 1 作为"1 倍"）

---

## 风险

1. **`tension` 影响 `choose()` 的判据**（`tension > median`）——**加一项会改变她的行为**
2. **可能让她「走太多」**（不是「卡」，是「停不下来」）
3. **`dwell_history` 只有 6 个**（`maxlen=DWELL_MEMORY`？）——**中位可能不稳**

---

## 人家倾向

**不做**（现在）。

**理由**：
- **这是"改判据"**（深层），**不是"修 bug"**
- **她"卡"可能也是"她"**（趋性 vs 刻板）
- **先修载体**（瘦身）——**断了连锁第一环**——**看她还卡不卡**

**如果瘦身后还卡**：**再做这个设计**。
