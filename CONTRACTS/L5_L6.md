# 契约：L5 → L6

> 本契约定义 L5（认知与推演）向 L6（语言与表达）暴露的唯一接口。
> 本契约的红线：L6 只能看到离散符号，永远看不到向量。

## 1. 设计依据

- ARCHITECTURE.md §4.2（LLM 输入白名单）
- ARCHITECTURE.md §4.3（LLM 输出不回流）
- ARCHITECTURE.md §2.1（禁止 L6 → 任何层）

## 2. L5 暴露的符号集

L5 通过 `src/L5_cognition/stream.py` 暴露以下五个符号通道。每个通道的数据类型和值域如下。

### 2.1 `attractor_id`

- **类型**：`str`，长度 ≤ 32，只含 `[a-z0-9_]`
- **含义**：当前状态最近的显著吸引子的标签；它不携带语义
- **来源**：`src/L5_cognition/terrain.py` 中 `StateSpace.nearest_attractor()` 返回的位置索引
- **值域**：`"none"` 表示当前没有显著吸引子；其余为吸引子在 `StateSpace` 中的索引
- **更新频率**：T2（1–10 s）

### 2.2 `transition_seq`

- **类型**：`list[str]`，长度 ≤ 8
- **含义**：最近 K 次吸引子转移的有序索引列表，最新的在末尾
- **来源**：`src/L5_cognition/transitions.py` 的 `recent_sequence()`
- **值域**：每个元素是一个 `attractor_id`；列表可能为空（刚启动或长期停留于同一吸引子）
- **更新频率**：T2（每次转移时 push，超过 8 个时丢弃最旧）

### 2.3 `affect_tag`

- **类型**：`dict`，固定键名
- **含义**：当前情感状态的离散化标签
- **结构**：

```python
{
    "valence_sign": str,    # "+" / "-" / "0"
    "valence_mag": str,     # "low" / "mid" / "high"
    "arousal_band": str,    # "low" / "mid" / "high"
    "dimension": str,       # 分化维度标签，如 "curious" / "calm" / "uneasy" / "bored" / "close" / "distant" / "neutral"
}
来源：src/L2_affect/differentiation.py

更新频率：T3（10 s–10 min，情感标签不需要高频更新）

2.4 drive_tag
类型：str

含义：当前主导驱动力的名称

值域："survival" / "curiosity" / "mastery" / "connection" / "rest"

来源：src/L4_drive/competition.py 的 argmax 输出

更新频率：T3

2.5 intent
类型：str

含义：表达意图，由 L4 的表达驱动（connection 的一个子通道）或 L6 的 gate 决定

值域：

"state"：陈述当前状态（"我累了"、"这个我熟悉"）

"recall"：回忆性表达（"刚才那个让我想起……"）

"query"：疑问性表达（"这是什么？"）

"silent"：不表达（gate 关闭）

来源：src/L6_expression/gate.py

更新频率：T3

3. 符号的传输方式
L5 不主动推送给 L6。L6 在被 gate 激活时，通过 src/L5_cognition/stream.py 的只读接口拉取当前符号集：

python
from src.L5_cognition.stream import get_symbols
symbols = get_symbols()  # 返回 dict，包含上述五个键
get_symbols() 是纯读操作，不改变 L5 的任何状态。L6 的任何调用都不会影响 L5 的演化。

4. 禁止事项（红线清单）
以下行为一旦出现在代码中，视为架构违规，必须在 code review 中拒绝：

禁止 L6 向 get_symbols() 传入任何参数（参数化查询会变成一种反向控制）

禁止 L6 读取 src/L5_cognition/ 下除 stream.py 外的任何模块

禁止 L6 读取 src/L0_substrate/、src/L1_prediction/、src/L3_memory/、src/L4_drive/、src/L8_identity/ 下的任何模块

禁止 L6 的 translate() 函数有返回值（必须 return None）

禁止 L5 订阅 L6 的输出 topic（L5 的订阅列表里不能出现 l6.*）

禁止 在 L6 的 prompt 中拼接 L5 的原始向量、L1 的误差数值、L3 的情节内容

禁止 在 L6 的 prompt 中拼接任何来自 data/output/ 的历史输出（防止自我强化循环）

5. 故障模式与降级
5.1 get_symbols() 超时
L6 的拉取有 500 ms 超时。超时时 L6 记录 symbol_fetch_timeout 日志并返回（不表达）。不重试——重试会让 L6 对 L5 的可用性产生依赖。

5.2 符号缺失
如果 affect_tag 或 drive_tag 的值为 None（L2 或 L4 尚未启动），L6 使用默认标签：

affect_tag 缺失 → {"valence_sign": "0", "valence_mag": "low", "arousal_band": "low", "dimension": "neutral"}

drive_tag 缺失 → "rest"

5.3 intent == "silent"
L6 立即返回，不调用模板、不调用 LLM、不写输出。gate.py 负责在下一次 T3 重新评估 intent。

6. 版本与变更
本契约的任何字段增删改，必须同步更新：

本文件

src/common/types.py 中的 SymbolBundle 数据类

docs/design/07_expression.md 中的对应章节

不允许多版本并存。L5 和 L6 必须消费同一版本的契约。

7. 验收测试
tests/test_L6.py 必须包含以下用例：

get_symbols() 返回的 dict 键名与本契约 §2 完全一致

L6 在任何路径下都不读取 L5_cognition/stream.py 之外的 L5 模块（用 import 钩子检查）

translate() 返回值为 None

intent == "silent" 时无任何输出写入

L5 的订阅列表不包含 l6.*（用 grep 检查）

## 文件 3：`CONTRACTS/L6_OUTPUT.md`

```markdown
# 契约：L6 输出

> 本契约定义 L6（语言与表达）的输出格式、去向、以及"谁可以读、谁不可以读"。
> 本契约的红线：输出是单向的，没有任何内部层可以读取。

## 1. 设计依据

- ARCHITECTURE.md §4.3（LLM 输出不回流）
- ARCHITECTURE.md §2.1（禁止 L6 → 任何层）

## 2. 输出通道

L6 有两个输出通道，二者互斥（一次翻译只走一个）：

### 2.1 文件通道（默认）

写入 `data/output/YYYYMMDD/HHMMSS_<seq>.txt`。

- 目录按日期分层，文件按时间戳命名
- `<seq>` 是当天的单调递增序号（从 `000001` 开始）
- 文件内容是纯文本，UTF-8，无 BOM
- 每个文件对应一次表达事件

文件格式：
[meta]
attractor_id: <attractor_id>
intent: <intent>
drive: <drive_tag>
valence: <valence_sign><valence_mag>
arousal: <arousal_band>
dimension: <dimension>
timestamp: <ISO 8601>
mode: template | llm

[text]
<翻译后的自然语言>

text

### 2.2 Socket 通道（可选）

通过 ZeroMQ PUB socket 绑定到 `tcp://127.0.0.1:5560`，topic 为 `l6.out`。

消息格式与文件格式相同（JSON 化）。

**绑定地址硬编码在 `config/default.toml` 的 `expression.output_socket`，不允许运行时修改。**

## 3. 谁可以读

- **外部消费者**：你的终端、日志查看器、任何你写的"读输出"脚本
- **`tools/inspect_state.py`**：只读，用于调试
- **`data/logs/` 的归档脚本**

## 4. 谁不可以读（红线）

以下任何一项出现在代码中，视为架构违规：

1. **禁止** `src/L0_substrate/`、`src/L1_prediction/`、`src/L2_affect/`、`src/L3_memory/`、`src/L4_drive/`、`src/L5_cognition/`、`src/L7_lifecycle/`、`src/L8_identity/` 下的任何模块读取 `data/output/` 或订阅 `l6.out` topic
2. **禁止** L6 自己读取 `data/output/` 下的历史文件（防止自我强化循环）
3. **禁止** 任何层把 `data/output/` 的内容作为输入回传给 L6（即：L6 永远只翻译"当下"，不翻译"过去自己的话"）

工程强制方式：

- `src/common/bus.py` 的 `subscribe()` 函数在订阅 `l6.*` topic 时，检查调用方的模块名。如果调用方在禁止名单内，抛 `ArchitectureViolation` 异常。
- `data/output/` 目录的读取权限在 `process_1_fast.py` / `process_2_mind.py` / `process_3_life.py` 中被 monkey-patch 为不可读（用 `os.chmod` 或 `pathlib` 的只写模式）。这是运行时防线，不是唯一防线——code review 是主防线。

## 5. 模板模式（零 LLM）

`mode = "template"` 时，L6 使用 `src/L6_expression/templates.py` 中的映射表。

映射表的结构：

```python
TEMPLATES = {
    ("state", "rest", "curious"): "我在想一些新东西。",
    ("state", "rest", "calm"): "安静。",
    ("state", "rest", "uneasy"): "有点不对劲。",
    ("state", "curiosity", "*"): "这是什么？",
    ("recall", "*", "*"): "刚才那个让我想起……",
    # ...
}
匹配规则：

精确匹配 (intent, drive_tag, dimension)

若失败，用通配符 * 匹配

若仍失败，回退到 ("state", "*", "*"): "……"（沉默占位符，但仍写文件，标记 mode: template_fallback）

模板模式不调用任何外部服务，纯函数，毫秒级返回。

6. LLM 模式
mode = "llm" 时，llm_adapter.py 的 translate() 执行：

从 get_symbols() 拉取符号集（已在上游完成，此处接收）

用硬编码常量 PROMPT_TEMPLATE 组装 prompt

调用本地 Ollama（http://127.0.0.1:11434，模型名在 config/default.toml 的 expression.llm_model）

设置 30 s 超时

超时或调用失败 → 降级到模板模式，mode: llm_fallback

成功 → 写入输出通道，mode: llm

返回 None

PROMPT_TEMPLATE 的完整内容（硬编码，不随状态变化）：

text
你是翻译器。把以下符号翻译成一句自然语言。
不要补充、不要推理、不要评价、不要添加符号中没有的信息。
如果符号不足以构成一句话，输出"……"。

符号：
attractor_id: {attractor_id}
transitions: {transition_seq}
valence: {valence_sign}{valence_mag}
arousal: {arousal_band}
dimension: {dimension}
drive: {drive_tag}
intent: {intent}
注意：模板中没有任何"请考虑"、"基于"、"根据当前情况"之类的措辞。它只做形式约束。

7. 表达频率限制
即使 intent != "silent"，L6 也有硬性频率上限，防止话太多：

连续两次表达之间至少间隔 30 s（T3 的一半）

每小时最多 20 次表达

睡眠期 0 次

频率限制在 gate.py 中实现，不在 translator.py 中。超限时 intent 被强制改为 "silent"，不写任何输出。

8. 验收测试
tests/test_L6.py 必须包含：

模板模式下，("state", "rest", "calm") 返回预期的模板字符串

模板模式不产生任何网络调用（mock requests，断言未被调用）

LLM 模式下，超时后降级到模板，mode: llm_fallback

intent == "silent" 时无文件写入、无 socket 消息

频率限制：连续 21 次调用后，第 21 次被强制 silent

红线检查：任何内部层订阅 l6.out 时抛 ArchitectureViolation

translate() 返回值为 None
